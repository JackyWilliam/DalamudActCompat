# 最高伤害数字格式与 HTML 脱战隐藏

## 最高伤害

在“自定义”中选中对应窗口的“最高伤害”栏目，“伤害数字格式”可选择：

- 缩写（K / M）：沿用原有缩写，例如 `128.5k`。
- 完整数字：例如 `128456`，不省略位数、不加千位分隔符。

经典榜、横版与 D/T/H 职能分栏分别保存；复制槽位和保存、取消编辑沿用现有配置流程。旧配置默认继续使用缩写。

横版只有一个最高伤害栏目时显示技能和数值；旧自定义布局如果将技能与数值分成两个槽位，则在数值槽位调整格式，保留分列布局。

## HTML 悬浮窗

在悬浮窗页面选中一个 HTML 窗口，在该窗口的设置中勾选“脱战隐藏”。这是每个实例自己的设置，默认关闭，没有新增全局开关。

- 已打开的窗口脱战时隐藏，进战时恢复。
- 临时隐藏保留浏览器实例和启动显示偏好。
- 编辑窗口位置时暂时显示，完成编辑后恢复脱战隐藏。
- 手动关闭的窗口不会因进战重新打开。
- 原有游戏失焦隐藏规则继续生效。

## 验证

PackageSmokeTests 的 `--display-options-only` 覆盖数字格式、旧配置默认值、保存/复制、窗口间隔离，以及真实 WinForms 窗口的进战/脱战/编辑/失焦/手动关闭行为。测试窗口位于屏幕外且不激活，不启动游戏或 WebView、不操作鼠标。
