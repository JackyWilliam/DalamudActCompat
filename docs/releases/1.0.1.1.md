# v1.0.1.1

## 本次更新

- **「悬浮窗」页可以看到 WebSocket 地址了**（玩家反馈）：WebSocket 服务一直随解析器启动，只是界面上没有显示。现在「悬浮窗」页的列表下方多了「WebSocket 地址」，点开可以复制地址、修改端口。
  - 在外部浏览器或 OBS 里用悬浮窗：在悬浮窗网址后面加上 `?OVERLAY_WS=` 和这个地址。帮助页「悬浮窗」一节有步骤。
  - 打开「允许局域网内的其他设备连接」后，手机、平板或另一台电脑也能连，弹窗里会显示这台电脑的局域网地址。
  - 保存时会先试新设置：端口被别的程序占用或者起不来，就保持原来的设置，不影响解析器。
- **局域网里的其他设备不能通过 WebSocket 向游戏发指令**：开放局域网访问后，其他设备只能读取战斗数据；通过 PostNamazu 发指令、打开网页、弹出目录选择这三类调用只对这台电脑上的悬浮窗开放。
- **FFLogs「选择战斗…」不再漏掉最后一场**（zhui-zi 贡献）：1.0.1.0 里，日志里的最后一场战斗有时不会出现在选择列表中。
- **安装包小了一半多**（zhui-zi 贡献）：核心包从约 32 MB 降到约 15 MB，Host 包从约 11 MB 降到约 2 MB，更新和首次下载更快。功能没有删减。
- **运行更省资源**（zhui-zi 贡献）：减少了战斗中每帧的内存分配和与 Host 之间的数据开销；AI 助手的辅助进程空闲 10 分钟后自动退出，需要时再启动。

## 已知情况

- 这一版的改动经过了自动测试和代码核对，**没有在游戏里实际验证过**。如果更新后触发器、鲶鱼精等 ACT 插件不工作，系统通知不弹，或者 AI 助手连不上，请在 DACT 里点「反馈」并附上诊断日志。
- 系统通知换了实现方式：在 Windows 通知中心里显示的名称变成「DACT」，以前在 Windows 里给它单独设过通知选项的话需要重新设一次。
- 帮助页里的截图还是 1.0.1.0 的：「悬浮窗」页那张图上没有新的「WebSocket 地址」按钮，图里左下角的版本号也还是 v1.0.1.0。按钮在列表下方「全部悬浮窗」一栏里。
- FFLogs 日志上传仍然没有用真实战斗完整上传验证过，情况同 1.0.1.0。

## 使用说明

通过原插件订阅更新至 1.0.1.1，更新后请完整重启游戏。配置、好友和云备份都不受影响。第一次启动 1.0.1.1 时会下载一次新的 Host。

## 验证范围

Release 构建、Scanner、包冒烟、Host 冒烟与各项触发器回归通过。新增的检查：WebSocket 地址切换（改端口、改监听地址、端口被占用时拒绝、绑不上时回滚）；「仅本机」调用限制（对端地址判定、其他设备被拒绝、本机与进程内调用放行，以及一次真实回环 WebSocket 连接上的 PostNamazu 调用）；Host 共享程序集从安装目录补齐；Claude 请求的认证头；悬浮窗页与新弹窗在 15 款皮肤、六种语言、两种宽度、三档字号下的排版；繁中、日语、德语、法语的词条齐全、占位符一致。
