# v1.0.0.7

## 本次更新

- **恢复抹茶的 FATE 提醒、跨服排队提示，以及银山雀儿的 FATE 功能**：7.58 更新后，这两类数据包换了编号，当时还没有公开的新编号。为了不把无关数据误当成 FATE 或排队信息，DACT 从 1.0.0.4 起暂停了这几项功能。现在抹茶上游已经公开了 7.58 的新编号（国服、国际服相同），DACT 补上后，FATE 提醒、跨服排队的位置和等待时间重新可用，银山雀儿依赖 FATE 的功能也一并恢复。

## 已知情况

- 这两个新编号目前只有抹茶上游这一份公开来源：它由 7.57 与 7.58 两版客户端对比得出，并在国服 7.58 客户端上核对过，DACT 还没有在游戏里实测。如果遇到 FATE 提醒或排队提示不对，请反馈。

## 使用说明

通过原插件订阅更新至 1.0.0.7，更新后请完整重启游戏。配置、好友和云备份都不受影响。第一次启动 1.0.0.7 时会下载一次同版本的 Host。

## 验证范围

Release 构建与 Host 冒烟测试通过。抹茶两地区 7.58 表 28 项逐项核对：真实抹茶 DLL 能从 7.58 的 FateInfo 包读出 FATE 开始时间和时长，从 WorldVisitQueue 包读出排队位置和等待时间；7.57 旧编号、银山雀儿占位编号和方向不对的包仍不会被识别。银山雀儿的 FateInfo 两地区都改为同一个 7.58 编号。抹茶上游表里另外 26 项与 DACT 原有的 7.58 表完全一致。以上为离线验证。
