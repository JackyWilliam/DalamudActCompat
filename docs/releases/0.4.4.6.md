# v0.4.4.6

战斗统计新增「显示范围」，入口位于插件主界面的「战斗统计」栏目。

- **按榜单设置**：默认选项，沿用原来的 8/24 人、队伍选择和仅自己等显示设置。
- **跟随解析范围**：按「概览 → 基础设置 → 游戏解析范围」显示已记录的玩家。「所有人」可显示队外玩家；「自动」跟随实际单人、小队或团队状态。经典榜、横版和职能分栏均支持。
- 切换显示范围会同步更新排名、占比和合计，保留已有统计；切回后恢复各榜单原有的筛选设置。选择可保存并随云配置恢复。
- 跟随模式下，经典榜的 8/24 人按钮显示为「列表／平铺」，用于切换布局；人数由解析范围决定。

解析范围只影响实际收到并记录的数据；扩大范围不会补回之前未解析的数据，旧历史记录也不会凭空增加队外玩家。

更新后请完整重启游戏，以加载配套解析组件。
