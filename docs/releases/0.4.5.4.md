# v0.4.5.4

## 本次更新

- 好友抽屉改为标签下方的列表独立滚动，顶部状态与「好友 / 申请 / 添加」标签固定显示；滚动条更细，各标签分别保留滚动位置。
- 「战斗统计 → 自定义」新增两项独立控制：「底板不透明度」与「彩色数据条不透明度」。底板全透明时仍可保留彩条，方便在游戏背景上阅读数据；经典榜、D/T 和 H 分别保存设置。
- 修正英、日、德、法帮助中对角色面板概率的说明；统一日语 FFLogs 术语与统计范围用词，整理长文本空格，修正德语「脱战隐藏」「折叠」及称呼不一致的问题。
- 改善自定义面板在窄窗口和长翻译下的按钮换行与提示布局。

## 更新说明

- 旧配置首次升级会保留原有彩条浓度，之后可分别调整底板与彩条；文字不受这两项不透明度设置影响。
- 请通过插件管理器更新，并完整重启游戏以加载新版本。
- 原有账号、皮肤、好友备注、触发器和语音设置保留。
