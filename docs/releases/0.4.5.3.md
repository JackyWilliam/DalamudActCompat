# v0.4.5.3

## 本次更新

- 新增繁体中文、日语、德语和法语界面，连同简体中文与英语共支持六种语言，可在「设置与账号 → 界面语言」即时切换。
- 新增「听雨窗」彩蛋皮肤：灰蓝雨窗、附着玻璃的细密水滴和动态滑落水痕，支持背景折射与柔和高光。
- 补齐好友状态、备注、聊天、快捷回复、统计预览、帮助，以及扩展更新、FoxTTS 切换和内存保护等常用提示的翻译。
- 改善长文案在窄窗口与大字体下的显示：导航标签可缩略并悬停查看全文，好友备注按钮会按空间自动换行。

## 更新说明

- 请通过插件管理器更新，并完整重启游戏以加载新版本。
- 原有账号、皮肤、好友备注、触发器和语音设置保留。
- 本次多语言适配覆盖 DACT 自身界面；第三方插件的界面、原始通知和诊断仍由对应组件决定语言。
