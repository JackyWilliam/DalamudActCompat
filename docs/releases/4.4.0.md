# v4.4.0

## 本次更新

- 适配 7.56 热修客户端 `2026.09.15`：更新 ACT 解析器、解混淆依赖与网络事件表，并同步抹茶、银山雀儿使用的事件映射。修正旧事件编号无法匹配新客户端技能包的兼容问题。
- 新增皮肤系统：一级及以上赞助账号可永久解锁「艾欧泽亚」浅色皮肤，资格由后台人工设置；另有可通过探索客户端发现的彩蛋配色。
- 浅色皮肤复用本机游戏的窗口、按钮、标签和图标素材；优化文字居中与 Logo 圆角，补齐云同步、好友状态和下拉列表的金属边框，修正主窗／好友栏底边及布局编辑器保存、取消按钮位置。
- 战斗统计可分别设置背景颜色与不透明度，支持恢复默认和完全透明，改善文字可读性。
- 新增「团队秒伤」槽位内容：在布局编辑器添加或选择槽位后启用。按全队总伤害除以有效战斗时长计算，包含已归属的极限技，不受「只显示自己」及职能筛选影响。升级不会改变现有槽位布局。
- 皮肤页支持预览、应用与明确的退出操作；启用游戏内爱发电入口。
