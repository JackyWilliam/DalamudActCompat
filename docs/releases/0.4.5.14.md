# v0.4.5.14

## 本次更新

- 适配 Triggernometry 2.2.1.0 新增的 PictoACT 绘图写法：按轴跟随实体（如 `ID, z=0`）、实体当前目标与按距离选人（`.Target`、`.NearPlayer1`、`.FarPlayer1` 等）、`polardir` 方向坐标、Scale 的 `_d3` 三维距离以及 `mod(x, y, min)`。此前用到这些写法的绘图（例如绝亚历山大触发器包）会被整条丢弃，不再显示。
- 修正两处与原版 Triggernometry 计算不一致的绘图表达式：`2√2`、`2(…)` 这类省略乘号的写法按原版优先级计算，避免落点偏移；留空的数值（如 `delay:`）按 0 处理，不再导致整条绘图丢失。
- 修复触发器偶发漏报、晚报或误报：日志与区域、战斗状态按原顺序送达；日志引用尚未同步的实体时短暂等待；触发器防重复与延时改用游戏日志时间；战斗开始与结束不再被合并；Host 重启后不再重放过期旧日志；事件丢弃会计入运行状态；已授权的语音不会被慢速语音服务挤掉。

## 使用说明

通过原插件订阅更新至 0.4.5.14，更新后完整重启游戏。
随包 Triggernometry 仍为 2.2.0.1；已自行更新到 2.2.1.0 的用户无需回退，新版绘图写法可正常显示。
Host 在战斗中重启时，触发器运行时变量仍会清空，属于进程重启的固有限制。
