# v1.0.0.2

## 本次更新

- **插件本体恢复到约 31 MiB**：1.0.0.1 为了尽快修好宝宝椅（Triggernometry）「故障」，把 Host 组件放进了插件本体，本体变成约 42 MB，国内部分网络通过卫月下载容易超时。1.0.0.2 把 Host 改回单独下载：插件本体由卫月下载，Host 由 DACT 自己下载，支持断点续传和备用地址，已经下过的同版本不会重复下载。
- **Host 只用同版本**：Host 下载失败时，不再悄悄改用电脑里旧版本留下的 Host（1.0.0.0 宝宝椅「故障」就是这样来的），而是弹出「核心组件」窗口说明下载失败，可以一键重试。重试成功后宝宝椅等扩展会自动启动，不用重启游戏；下载完成前，战斗统计、悬浮窗等基础功能照常使用。
- **开屏动画「每次打开」修复**：动画没放完就关掉控制中心，以前动画会在后台接着计时，再打开时要么从上次的进度接着放，要么（关得久了）直接进主界面不播放，得再关开一次才恢复。现在关闭控制中心就会结束动画，下次打开总是从头播放；在关闭的淡出过程中立刻重新打开也算一次新的打开。
- **开荒进度的阶段与 FFLogs 一致（光暗未来绝境战）**：以前按「血量最高的敌人换了名字」算阶段，冰水晶转场和 P4 双 Boss 回归都会多算一个阶段，最多显示到 P7。现在按 FFLogs 的划分：P1 绝命战士、P2 希瓦·米特隆（冰水晶转场仍算 P2）、P3 暗之巫女、P4 双 Boss、P5 潘多拉。以前记下的绝境战记录在更新后打开时会自动按新规则重算（需和记录时是同一种客户端语言）。其他副本的阶段算法不变。

## 使用说明

通过原插件订阅更新至 1.0.0.2，更新后请完整重启游戏。这次不需要重新登录。

第一次启动 1.0.0.2 时，DACT 会下载对应版本的 Host（约 11 MB）；如果弹出「核心组件」窗口提示下载失败，检查网络后点下载按钮重试即可。

## 验证范围

Release 构建、完整包冒烟测试与 Host 冒烟测试通过；发布脚本校验插件本体不含 Host、资源清单列出且只列出一个本版本 Host 包，本体不超过 32 MiB；包冒烟新增「缓存里有旧版 Host 包且下载全部失败时，Host 报告不可用、不使用旧版本，而 Cactbot 与随包扩展仍可沿用上一版」的检查，以及「开屏动画开始 0.7 秒或 10 秒后关闭再打开、或在关闭淡出中重新打开，动画都从头开始」的检查；新增光暗未来绝境战阶段检查（逐次采样的阶段推进、P2 中希瓦不会跳到 P4、转场留在 P2、旧记录重算与保存、其他语言和其他副本不改）。
