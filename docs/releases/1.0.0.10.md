# v1.0.0.10

## 本次更新

- **人多时同步给 Host 的数据减少约一半**（玩家反馈 Host 占用高）：DACT 每 30 毫秒把周围角色的位置、血量和增益减益同步给运行触发器的 Host。以前每次都把每个角色的全部增益减益重发一遍，同时开着几个 Host 就打包几遍，Host 收到后再把所有角色重建一遍。
  - 增益减益没有变化的角色不再重发这一部分，Host 沿用上一次的结果。
  - 同一份数据只打包一次，供所有 Host 共用。
  - Host 只重建这次有变化的角色。
  - 没有 Host 在运行时不再采集。
  - 测量结果（150 名玩家加 300 个 NPC、所有角色都在移动的最坏情况）：每次同步的数据从 407 KiB 降到 234 KiB；游戏主线程打包数据的耗时，开三个 Host 时从 5.42 毫秒降到 0.81 毫秒，只开一个时从 1.57 毫秒降到 0.81 毫秒；Host 处理一次的耗时从 1.93 毫秒降到 1.09 毫秒。
- **适配仿生石（Simulant）v0.1.0.0**：上一版导入 v0.1.0.0 只会提示尚未适配，现在可以导入使用，v0.0.4.2 继续支持。这部分适配只做了离线检查，还没有在游戏里验证过，详见下面的「已知情况」。和原版不同的地方：
  - 仿生石自带的自动更新在 DACT 里不执行，要换版本请重新导入 DLL。
  - 它的配置文件保存在 DACT 的 ACT 数据目录里。
  - 高于 v0.1.0.0 的版本仍然不加载，并说明原因。
- **随包的鲶鱼精邮差带上了调用调度器**：仿生石 v0.1.0.0 的原生调用都要经过邮差的调用调度器。上游在今年 5 月已经把它合入源码，但正式发布版仍是不含它的 1.3.6.6。DACT 随包的邮差改为按上游自己的构建步骤、从上游源码（提交 `521007c`）构建的版本，版本号仍显示 1.3.6.6。
  - 更新后第一次启动，会像以往随包插件更新那样请你确认一次这项变更，确认后邮差才会加载。
  - 这份邮差不再跟随在线更新，否则会被版本号相同的官方包换回去。上游发布新的正式版后，DACT 会换回官方包。
- **缺少 WebView2 Runtime 时提示正确的原因**（玩家反馈）：系统里没有 Microsoft Edge WebView2 Runtime 时，Cactbot 等网页悬浮窗打不开，以前却提示「插件随包的 WebView2Loader.dll 缺失，请重新安装插件」，重装并不能解决。现在提示「未检测到 Microsoft Edge WebView2 Runtime」，并说明安装微软官方的 WebView2 Runtime 后重新打开窗口即可。网吧等精简过的系统容易遇到这种情况。
- **诊断日志保留完整的异常信息**：「复制诊断日志」和反馈里附带的日志，以前只留下出错时 DACT 自己的那几行，是什么错误、错误出在哪个组件都被略去了。现在出错的整段记录都会保留，其它插件的日志和以前一样不会带上。

## 已知情况

- 仿生石 v0.1.0.0 的适配和新的随包邮差都还没有在游戏里验证过：初始化、防火墙的开启与关闭、切换地图、开始和停止模拟、卸载，以及邮差的标点和命令。遇到问题请在 DACT 里点「反馈」提交；仿生石也可以重新导入 v0.0.4.2。
- 同步数据的优化是用测量验证的，还没有在游戏里实测。Host 自身的内存占用和触发器的计算量这次没有改。
- 其它绝本（巴哈姆特、亚历山大、龙诗、欧米茄）的开荒进度阶段仍按「主要 Boss 换了名字」来数，可能和 FFLogs 的阶段不一致；光暗未来和绝神兵已按 FFLogs。

## 使用说明

通过原插件订阅更新至 1.0.0.10，更新后请完整重启游戏。配置、好友和云备份都不受影响。第一次启动 1.0.0.10 时会下载一次同版本的 Host 和随包 ACT 插件。

## 验证范围

Release 构建、Scanner、包冒烟、Host 冒烟与各项触发器回归通过。新增或扩充的检查：同步数据里未变化的增益减益由 Host 沿用、与整份重发的结果一致，同一份数据只打包一次；随包邮差的文件摘要固定，上游发布新正式版时发布前的依赖检查会提醒换回；仿生石 v0.0.4.2 和 v0.1.0.0 两个版本改写后的逐项检查（分别 9 项和 12 项，只检查改写结果，不加载、不运行 v0.1.0.0），更高版本不加载并给出说明；缺少 WebView2 Runtime、缺少随包文件和其它「找不到文件」三种情况分别给出各自的提示；诊断日志保留出错记录的完整内容，同时不带入其它插件的日志。
