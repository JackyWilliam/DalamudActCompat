# v0.4.5.9

## 本次更新

- 优化登录与密码找回界面，保留 DACT 横向布局；修复登录状态、错误提示和账号切换时的状态同步问题。
- 接入 DACT Discord 机器人绑定和密码找回。更新后，未绑定账号需先完成绑定才能继续使用 DACT；一个 Discord 账号可绑定 3 个 DACT 账号。绑定完成后自动进入，提示只限制 DACT 窗口，不影响游戏内其他操作。
- 为仍持有原密钥的账号自动建立云备份恢复保护，后续通过已绑定的 Discord 账号找回密码时可继续使用原云备份。
- 改善共享、抹茶和第三方 Host 的启动、停止、崩溃恢复与通信检测；修复登出、权限更新、插件安装及配置恢复交错时的异常恢复问题。
- 补齐手动安装 ACTLogsUploader 和绝神兵工具的兼容与第三方 Host 接线。以上第三方插件仍需用户自行提供，不随 DACT 安装包分发。
- 修复艾欧泽亚皮肤的文件选择窗口、路径按钮颜色和按钮左右边距；改善听雨窗等皮肤的按钮辨识度，修复鼠标点击后多余的黑色焦点框，保留键盘焦点提示。
- 修复好友聊天发送或接收新消息后未自动滚到底部的问题；上翻查看历史时保留当前位置，并提供回到底部入口。

## 更新与绑定说明

- 通过原插件订阅更新至 0.4.5.9，并完整重启游戏；原有配置继续保留。
- 首次进入时若提示绑定：复制绑定码，点击进入 DACT Discord，在服务器右侧成员列表的 Bot 分组找到 DACT 并私聊；输入并选择 `/dact`，点「绑定账号」后粘贴提交，回到游戏即可。
- 密码找回可在同一机器人菜单中选择「找回密码」。此前已彻底丢失原密钥、且尚未建立恢复保护的旧备份，不能仅凭此次更新恢复。
- 本次不包含六绝新皮肤及其解锁功能，仍在设计阶段。
