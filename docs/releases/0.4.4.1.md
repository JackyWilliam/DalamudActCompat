# v0.4.4.1

## 战斗统计

- 修复已切换到“24 人本”仍只显示本队 8 人的问题，补齐联盟另外两队的成员读取。
- 修复没有战斗记录时，自定义编辑器“页面预览”底部的全队属性栏不可见的问题。

## 皮肤与云同步

- 彩蛋解锁记录和已选皮肤随加密云备份恢复，修复恢复后再次保存或重启丢失解锁的问题。
- 检测到默认配置时，自动和手动云同步都会跳过上传，保留已有云端备份；无法确认是默认内容的第三方配置仍保留同步。
- 新增可探索的「绯梦霓光」配色，精简皮肤预览页多余的关闭按钮。

## 账号与聊天

- 赞助者名字显示为红色，后方新增皇冠与等级方框；管理员等其他标识排在其后。赞助资格永久有效，等级由后台设置。
- 首次获得赞助身份时显示庆祝窗口；确认后再次登录或升级等级不重复弹出，已有赞助者也会获得一次提示。
- 聊天已读位置随账号保存，成功同步后重新安装也能恢复；新来信仍正常显示未读。
- 修复从来信气泡点击“全部展开”没有清除未读的问题；现在会打开对应聊天并回到最新消息，也修复气泡盖住聊天时按钮点击失效的问题。
- 聊天窗口采用 DACT 自定义标题栏，保留拖动、关闭、缩放及身份标识。
- 管理后台可查看账号最近上报的 DACT 版本，方便定位版本相关问题。

## 更新说明

更新后请完整重启游戏。旧版本重装已经丢失的本机已读记录无法追溯恢复；更新后重新打开对应聊天，新已读位置会保存到账号。

仍安装错误编号 `4.4.0.0` 的用户，请先使用同一卫月仓库中的 **DACT 修复工具** 修复到 `0.4.4.0`，完整重启后再正常更新到 `0.4.4.1`；保留配置，无需重置插件数据。[修复工具说明](https://github.com/JackyWilliam/DalamudActCompat/tree/main/tools/DACT.Repair)

本次保留 7.56 热修解析适配。国服／国际服解析与合成数据回归已通过，实际副本、语音字幕及绘图仍需游戏内验收；本次不宣称之前报告的绝伊甸／绝妖星全部缺圈问题已经修复。
