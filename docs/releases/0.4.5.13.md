# v0.4.5.13

## 本次更新

- 修复启动时因 Discord 绑定状态尚未返回而自动打开控制中心的问题，精简主页也保持关闭。
- 自动登录本身不弹通知。Discord 绑定验证通过通知显示验证中、成功和失败；同一状态不会反复提示。
- 区分服务器确认“账号尚未绑定”和“暂时无法获取有效状态”，避免让已绑定用户误以为需要重新绑定。
- 保留原有绑定验证与功能权限限制，以及 0.4.5.12 的国服／国际服 7.57 适配。
- 同步 FFXIV ACT Plugin 3.0.3.3，纳入上游最新的 7.57 支持。

## 使用说明

通过原插件订阅更新至 0.4.5.13，更新后完整重启游戏。
需要查看主界面或处理绑定时，使用 `/dact` 或主动点击插件入口。
已绑定账号无需重复绑定；临时验证失败会自动重试，可通过 `/dact` 查看详情。
