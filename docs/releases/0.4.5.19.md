# v0.4.5.19

## 本次更新

- 适配 Triggernometry 2.4.1.1：中文维护版 2.4.1.1 重构了动作执行，DACT 此前无法加载它，扩展页“打开配置”没有反应。现已兼容，随包 Triggernometry 同步更新至 2.4.1.1。
- 插件清单补充 512 像素 PNG 图标地址：卫月会保留安装包内的清单，此前 DACT 的清单没有图标地址，折叠插件等读取已装插件信息的工具拿不到图标。

## 使用说明

通过原插件订阅更新至 0.4.5.19，更新后完整重启游戏。
已通过扩展更新器装上 Triggernometry 2.4.1.1 的用户，更新后触发器会恢复加载；仍为 2.3.0.0 的用户可继续使用，也会在确认随包更新后切换到 2.4.1.1。
图标地址随本版安装包写入本地清单，需要更新到本版后才会生效。

## 验证范围

兼容改写在 Triggernometry 2.3.0.0 与 2.4.1.1 上都通过 Host 与进程内两条改写路径、改写后结构断言和 IL 静态校验；CI 使用真实的 2.4.1.1 运行 Host、U7b 初始化顺序、事件时间基准、绘图诊断与清特效链回放。

Triggernometry 2.4.1.1 自身的功能与语义变化（例如条件中的数值比较）由上游维护，本版只保证它在 DACT 中加载、打开配置并沿用既有兼容桥接。触发器包的实战表现与图标在游戏内的显示，仍以更新后的实际使用为准。
