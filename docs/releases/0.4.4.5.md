# v0.4.4.5

## 自动解析范围与液态玻璃修复

- 「概览 → 基础设置 → 游戏解析范围」新增「自动（按实际组队）」：单人时仅自己，普通小队时小队成员，24人团队时团队成员；进队、退队后自动切换。
- 自动判断跟随实际组队状态，不受战斗统计窗口8/24人布局影响；现有手动选择保持不变，选择「自动」后即可启用。
- 自动范围同时用于解析器、伤害补算、治疗、死亡观测和DPS计时，支持配置保存及云同步恢复，已记录数据保留；原始日志与触发器不受影响。
- 修复液态玻璃白色卡片出现生硬方框的问题：去除重复叠加的底色和边框，恢复完整圆角及滚动裁剪，让卡片保持轻透；窗口偏白底色、黑色文字和折射效果保留。

## 更新说明

使用原卫月订阅正常更新，更新后请完整重启游戏。现有配置和已发现皮肤均保留。

仍安装错误编号 `4.4.0.0` 的用户，请先用同一仓库中的 **DACT 修复工具** 修复到 `0.4.4.0`，完整重启后再更新到 `0.4.4.5`；无需重置配置。
