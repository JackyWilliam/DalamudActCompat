# v1.0.0.5

## 本次更新

- **解析器更新到 FFXIV_ACT_Plugin 3.0.3.5**：这是官方针对 7.58 发布的解析器版本，另外加入了繁体中文地名。1.0.0.4 仍是 3.0.3.4。更新后新生成的 Network 日志第一行会写 `based on FFXIV_ACT_Plugin 3.0.3.5`。
- **7.58 改用官方解混淆配置，不再弹出「ACT 网络兼容性警告」**：1.0.0.4 发布时 Unscrambler.XIV 还没有 7.58 配置，只能用运行时兜底，启动会出现这条警告。现在官方 7.58.0 已发布：
  - 国际服直接使用官方 7.58 配置；
  - 国服与国际服是同一个版本号，但客户端文件里的位置不同，所以沿用 7.55h1 起的做法：使用同一套 19 项混淆操作码，密钥表仍从本机客户端读取。这 19 项已与公开的国服 7.58 数据逐项核对，全部一致。
  - 1.0.0.4 的兜底只还原 Machina 解析的 12 类包；查看装备、更新套装、队伍更新等另外 7 类混淆包当时没有还原，现在也按官方配置还原。

## 已知情况

- 7.58 的 FATE 与跨服排队数据包编号仍没有公开值：抹茶的 FATE 提醒、跨服排队提示，以及银山雀儿依赖 FATE 的功能继续暂不可用，等上游公开后恢复。
- 以前用 1.0.0.4 生成的日志不会因为更新而改变。需要上传 FF Logs 时，请在更新并重启游戏后打新的战斗，用新生成的日志上传。
- 解析器的繁体中文地名主要面向繁中客户端；DACT 国服、国际服版本不受影响，台服版本是否需要另行评估。

## 使用说明

通过原插件订阅更新至 1.0.0.5，更新后请完整重启游戏。配置、好友和云备份都不受影响。

## 验证范围

Release 构建、Scanner、包冒烟与 Host 冒烟测试通过。解析器 3.0.3.5 的 15 个文件与「用官方 GitHub 发布包（SHA-256 `9e148783…8011`）走同一套解包与补丁流程」得到的结果逐字节一致，FFLogs 日志头为 `This is IINACT 2.10.3.12 (API 1.6.0) based on FFXIV_ACT_Plugin 3.0.3.5`。Unscrambler.XIV 7.58.0 与 NuGet 官方包哈希一致，包内登记的源码提交为 perchbirdd/unscrambler `c5826c2`。7.58 检查改为：国际服选用官方配置、国服选用运行时密钥表（拒绝 7.57 等错误大小）、两地区与 Machina 7.58 表一致、合成的 ActorCast / ActionEffect 包能完整还原，翻译客户端仍走国际服配置。以上为离线验证，未在 7.58 游戏内实测初始化、战斗统计与 FF Logs 上传。
