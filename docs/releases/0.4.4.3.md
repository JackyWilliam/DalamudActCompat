# v0.4.4.3

## 外观更新

- 新增彩蛋皮肤「澄光流璃」与「无相玄墨」，发现后可在外观与皮肤中预览、应用，并随配置云同步保存。
- 澄光流璃采用偏白的半透明玻璃和墨色文字，实时模糊游戏背景，圆角边缘呈现折射、色散与悬停高光。
- 无相玄墨采用纯黑底色与灰白控件、文字，保留清晰的内容层次。
- 修复玻璃背景细纹理的颗粒感，增强边缘折射，并调整右上角关闭按钮的内边距。
- 修复云同步状态弹窗在部分字体缩放下始终显示多余滚动条的问题；内容超出窗口时仍可正常滚动。

## 更新说明

使用原卫月订阅正常更新，更新后请完整重启游戏。现有配置、已发现皮肤和统计背景设置均保留。

仍安装错误编号 `4.4.0.0` 的用户，请先用同一仓库中的 **DACT 修复工具** 修复到 `0.4.4.0`，完整重启后再更新到 `0.4.4.3`；无需重置配置。
