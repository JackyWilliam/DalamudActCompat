# v1.0.0.8

## 本次更新

- **战斗统计不再被旁人的战斗带着计时**（玩家反馈）：野外单人、没有组队也没开打时，附近只要有人打木人或打怪，战斗统计就开始计时，下面一直是「等待玩家数据…」。原因是「游戏解析范围」以前默认是「所有人」，旁人的战斗也会开一场统计，而榜单只显示自己和队友，于是只剩一个空的计时。
  - 「游戏解析范围」的默认值改为「自动（按实际组队）」：单人只统计自己，小队统计小队，24 人团队统计团队，进队、退队后自动切换。
  - 原来是「所有人」的配置，更新后会改成「自动」一次；战斗统计选了「跟随解析范围」的不改。想继续看附近所有人的数据，在「主页 → 基础设置 → 游戏解析范围」改回「所有人」即可，之后不会再被改动。
  - 即使选「所有人」，按榜单设置显示时也不再为一场只有队外玩家的战斗显示空计时；队伍里有人出手后照常显示。
- **职能分栏榜单不再一直带着滚动条**：「D / T 伤害榜」和「治疗 HPS 榜」展开时，窗口右侧总有一条滚动条；收起后窗口和里面的列表各有一条。两个榜单都已修好，行数确实放不下时才在列表里滚动。经典榜在大字号下收起时列表里多出的滚动条一并修复。
- **写反馈时不再锁住游戏**（玩家反馈）：以前打开「反馈」后，游戏和其他窗口都点不动。现在反馈是一个可以拖动的独立窗口，写到一半可以回游戏看一眼再接着写；添加截图也不用先关掉反馈。
- **反馈的描述框会自动换行**（多位玩家反馈）：以前一行写到头就看不见后面的字了。现在中文逐字换行、英文按词换行，复制和提交的仍是原文。
- **绝神兵的开荒进度不再多数阶段**（玩家反馈）：刚见到泰坦就显示 P5。原因是迦楼罗的分身、羽毛和伊弗利特的火狱之楔在本体离场时被当成了新阶段。现在按 FFLogs 的分法记：P1 迦楼罗、P2 伊弗利特、P3 泰坦、P4 拉哈布雷亚、P5 究极神兵。已经保存的记录会在打开时按同一规则更正。
- **副本里的每一把，最新的排在最上面**（玩家建议）：「战斗记录 → 近期战斗」展开一次副本后，以前从上到下是记录 1、2、3，打了一晚上要拉到底才看得到刚打完的那把。现在最新的一把在最上面，编号不变。
- **悬浮窗「⋯」菜单里的说明对齐了**（玩家反馈）：说明文字以前贴着菜单边，还会被多折一次行。
- **添加 Cactbot 悬浮窗时，下拉里同时显示本地名和原名**（玩家反馈），例如「职业量谱 / Jobs」；其余 Cactbot 模板补上了中文名和繁中、日、德、法译名。
- **随包 Cactbot 更新到 0.37.6**：上游这一版补了绝妖星 P3–P5 的时间轴和语音提示、驯兽师职业支持、7.56 与 7.58 的数据以及各语言翻译。已经装过的 Cactbot 会在更新 DACT 后自动升级，`cactbot/user/` 里自己的文件保留。

## 已知情况

- 其它绝本（巴哈姆特、亚历山大、龙诗、欧米茄）的开荒进度阶段仍按「主要 Boss 换了名字」来数，可能和 FFLogs 的阶段不一致；光暗未来和绝神兵已按 FFLogs。
- 仿生石（Simulant）上游在 11 月 14 日发布了 v0.1.0.0，DACT 的仿生石适配目前只在 v0.0.4.2 上验证过，新版还没有核对。
- 以上修复均为离线验证，还没有在游戏里实测。

## 使用说明

通过原插件订阅更新至 1.0.0.8，更新后请完整重启游戏。配置、好友和云备份都不受影响。第一次启动 1.0.0.8 时会下载一次同版本的 Host，并自动把 Cactbot 升级到 0.37.6。

## 验证范围

Release 构建、Scanner、包冒烟、Host 冒烟与各项触发器回归通过。新增或扩充的检查：解析范围的新默认值与旧配置迁移（「所有人」改为「自动」一次、之后手动选回不再改动、「跟随解析范围」保持、其它选项不动、恢复默认与云端恢复）；只有队外玩家的战斗在本队视图下不显示、队伍出手后恢复、只有队员倒地的战斗仍显示；绝神兵阶段按实际出现的敌人逐步核对，并用玩家描述的那一把（旧算法为 P5）核对更正为 P3。战斗统计窗口用真实界面库逐一核对 288 种布局（经典榜、D / T、治疗；展开与收起；有无标题栏和合计行；四种字号）都没有多余的滚动条，收起、展开动画与拖动定位的 48 组检查通过。随包 Cactbot 0.37.6 与官方发布包的摘要一致，安装与升级检查通过。
