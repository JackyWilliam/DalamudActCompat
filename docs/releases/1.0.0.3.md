# v1.0.0.3

## 本次更新

- **宝宝椅（Triggernometry）收日志不再被误判卡住**：DACT 会在日志引用了刚出现、还没同步过来的 NPC 时，让宝宝椅最多等 200 ms 再收这条日志，好让触发器读得到这个 NPC。以前判断时把日志里所有「以 4 开头的 8 位十六进制数」都当成 NPC 编号，状态剩余时间（例如 41A00000 其实是 20 秒）、伤害值、职业量谱和内存数值也被当成了 NPC，于是每出现一个新数值就白等 200 ms。战斗中这种情况每秒会发生好几次，宝宝椅的触发、TTS 和画图会一直晚 0～0.2 秒。现在只检查日志里真正存放 NPC 编号的字段，真正刚出现的 NPC 仍然会等。
- **扩展缺少必需权限时直接说明缺哪项**：银山雀儿等扩展需要某项权限才能启动（例如银山雀儿需要「访问游戏原生内存」），在默认的安全权限下以前会显示「故障」和一整段报错。现在显示「需要授权」，并提示在「权限」里打开哪一项，打开后扩展会自动重启。
- **权限检查日志不再刷屏**：抹茶每转发一行日志都会记一条权限检查，诊断日志被它占满；现在同一项权限的结果只记一次。

## 使用说明

通过原插件订阅更新至 1.0.0.3，更新后请完整重启游戏。这次不需要重新登录，配置、好友和云备份都不受影响。第一次启动 1.0.0.3 时会下载一次同版本的 Host（约 11 MB）。

## 验证范围

Release 构建、包冒烟与 Host 冒烟测试通过；新增「状态剩余时间、伤害值、量谱和内存数值不会让宝宝椅等待，而新出现的 NPC 仍会等待」「缺少权限时报出具体权限名、同一权限结果只记一次」的检查，并确认这两项检查在 1.0.0.2 的代码上会失败。
