# v1.0.0.0

## 本次更新

- **全新控制中心**：顶栏放全局搜索、云同步状态、反馈和帮助；左侧导航放主页、战斗统计、战斗记录、悬浮窗、扩展、好友、AI 助手，分隔线下是账号与云同步和设置。首次打开会有一段 1.0 新版导览，可随时跳过。
- **全局搜索**：按 Ctrl+Shift+K（可在设置里改键或关闭）或点击顶栏搜索框，设置项、页面和使用帮助一起搜，回车直接跳转，开关类设置可以在结果里直接切换。
- **皮肤**：每款皮肤都有自己的控件、下拉框、浮层和对话框样式；设置 → 外观与皮肤可以预览后再应用。艾欧泽亚使用游戏窗口的金属边框，悬停说明也套用同款外框；隐藏配色仍等你在客户端里发现。
- **好友**：好友从顶栏搬进左侧导航，独立的好友页与可单独打开的聊天窗口；收发消息有动效，来信气泡里可以直接「全部展开」打开聊天。
- **战斗记录**：独立窗口并入控制中心，新增「开荒进度」，记录每次打到哪里和最常见的团灭点。
- **战斗统计样式编辑器重做**：在页面预览里点选槽位，右侧属性自动切到所选槽位。
- **AI 助手**：诊断问题、战斗复盘、使用问答。默认关闭，需要你自己的 API Key，Key 只保存在本机。
- **反馈**：顶栏反馈按钮可提交问题、建议或其他，附截图、诊断日志与 AI 对话；回复会出现在好友 ·「官方通知」。
- **账号**：每个账号最多同时登录 5 台电脑，第 6 台登录时可以选择登出其中一台或全部登出；设备以 Windows 电脑名显示。
- **其他**：场景方案；DACT 样式的选文件 / 选文件夹窗口；登录与注册页右上角加入帮助；Triggernometry 与扩展更新检查在系统 DNS 解析失败时改用 Cloudflare / Google 的 DNS-over-HTTPS，更新源失败时显示具体原因并自动重试一次。

## 使用说明

通过原插件订阅更新至 1.0.0.0，更新后请完整重启游戏。

**更新后需要重新登录一次**：为了让「最多 5 台设备」按电脑名记录设备，1.0 发布时所有账号会统一退出一次，重新输入账号密码登录即可，配置、好友和云备份都不受影响。

AI 助手默认关闭，不开启就不会产生任何网络请求；开启后请求直接从你的电脑发到你填写的服务商，不经过 DACT 服务器。

## 验证范围

Release 构建、完整包冒烟测试与 Host 冒烟测试（含真实 Triggernometry 2.4.3.0 的改写与运行）通过；控制中心、好友、账号、封禁恢复、选文件窗口等原生 ImGui 界面测试通过；界面在简体中文、繁体中文、日语、德语、法语下核对布局。维护者在国服游戏内完成多轮实机试用。

DNS 兜底只解决解析失败；更新源节点本身不可达时仍可能超时，此时会提示原因并在下次检查时重试。
