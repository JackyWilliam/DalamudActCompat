# v0.4.5.17

## 本次更新

- 界面：修复繁体中文、日语、德语、法语界面在大字号或窄窗口下，控制中心快捷入口按钮文字被截断、悬浮窗管理的复选框和说明文字超出窗口、名称与网址输入框标签被挤出的问题；游戏区域与解析范围选择框也不再溢出。
- 翻译：修正悬浮窗管理相关的 30 余条译文，例如日语“关闭”状态误译为「閉店」、繁体中文“打开”按钮显示成「已開啟」；悬浮窗的“已打开”状态与“打开”按钮现在分开翻译。
- 战斗统计：修复在野外打木人时 DPS / rDPS 很快掉到接近 0 的问题。木人血量不变，游戏服务器不会对大部分攻击回传结算结果，DACT 之前只统计有结算结果的伤害；现在野外战斗按 ACT 统计的全部伤害计算，副本内仍与 FFLogs 的算法保持一致。
- 近期战斗：修复大字号或窄窗口下卡片文字重叠、汇总数字被截断、队员数值盖住名字的问题；副本分组前的箭头不再显示成"="，排序提示随当前 DPS 指标显示，没有逐事件明细时不再显示"0 伤害"。
- Discord 绑定验证的两条游戏内通知原来提示“使用 /dact”，但游戏内的命令是 `/actcompat`（`/dact` 是 Discord 机器人的命令），按提示输入没有反应，现已更正。
- 宝宝椅（Triggernometry）等扩展读取的实体“主人 ID”：没有主人的玩家和 Boss 现在与原版 ACT 一样显示为 0，此前为 3758096384（0xE0000000），会让按“主人 ID 为 0”区分玩家与宠物的触发器判断错误。DACT 自带的绘图不受影响。
- 云同步：之后版本新增的皮肤或彩蛋，在仍为本版本的设备上恢复配置、再上传时不再被重置为默认外观（本版本显示默认外观，但保留原选择）。

## 使用说明

通过原插件订阅更新至 0.4.5.17，更新后完整重启游戏。
游戏内打开 DACT 主界面请使用 `/actcompat`；`/dact` 只用于 DACT Discord 机器人的私信菜单（绑定账号、找回密码）。
多台电脑使用同一账号云同步时，建议都更新到 0.4.5.17，之后的新皮肤即可在各设备之间保留。
