# v0.4.4.0

## 本次更新

- 更正此前错误的 `4.4.0.0` 发布编号，正式版本统一为 `0.4.4.0`，保留全部已完成功能。
- 适配 7.56 热修客户端 `2026.09.15`：更新 ACT 解析器、解混淆依赖与网络事件表，并同步抹茶、银山雀儿使用的事件映射。修正旧事件编号无法匹配新客户端技能包的兼容问题。
- 新增皮肤系统：一级及以上赞助账号可永久解锁「艾欧泽亚」浅色皮肤，资格由后台人工设置；另有可通过探索客户端发现的彩蛋配色。
- 浅色皮肤复用本机游戏的窗口、按钮、标签和图标素材；优化文字居中与 Logo 圆角，补齐云同步、好友状态和下拉列表的金属边框，修正主窗／好友栏底边及布局编辑器保存、取消按钮位置。
- 战斗统计可分别设置背景颜色与不透明度，支持恢复默认和完全透明，改善文字可读性。
- 修复更换主界面皮肤后战斗统计出现米色底板的问题：经典榜、横版及职能分栏的颜色和透明度独立于皮肤，编辑预览不再叠加子窗口背景。
- 新增「团队秒伤」槽位内容：在布局编辑器添加或选择槽位后启用。按全队总伤害除以有效战斗时长计算，包含已归属的极限技，不受「只显示自己」及职能筛选影响。升级不会改变现有槽位布局。
- 皮肤页支持预览、应用与明确的退出操作；启用游戏内爱发电入口。

## 更新说明

更新后请完整重启游戏，使解析器和独立 Host 一起更新。赞助权益需要登录对应云账号，可在账号页刷新权益。

### 已安装错误编号 4.4.0.0 的用户

卫月只把数值更高的版本视为更新，因此不会自动从 `4.4.0.0` 降到 `0.4.4.0`。请先保留配置备份，再按顺序操作：

1. 在 `/xlplugins` 的已安装列表中禁用 DACT，点击垃圾桶卸载；不要选择「重置插件数据」或删除 `pluginConfigs`。
2. 完整退出并重新启动游戏，让卫月完成旧版本清理。
3. 在插件列表确认显示 `0.4.4.0` 后重新安装，再完整重启游戏。

普通卸载与配置重置是不同操作；本次更正发布编号并修复皮肤影响统计背景的问题，配置格式保持兼容。仍在 `0.4.3.1` 的用户正常更新即可，无需重装。依据：[卫月版本比较与卸载清理实现](https://github.com/goatcorp/Dalamud/blob/master/Dalamud/Plugin/Internal/PluginManager.cs)、[插件卸载与重置入口](https://github.com/goatcorp/Dalamud/blob/master/Dalamud/Interface/Internal/Windows/PluginInstaller/PluginInstallerWindow.cs)。

解析链版本：FFXIV ACT Plugin 3.0.3.1、IINACT 2.10.3.8、OverlayPlugin Core 0.19.108、Unscrambler.XIV 7.56.1；Machina 使用保留 DACT 兼容修改的源码分支并同步 7.56h 事件表。

已验证国服／国际服四种坦克无敌技能的合成事件解混淆、配置保存和原生界面交互。实际语音、字幕及副本绘图仍需游戏内验收；本次不宣称之前报告的绝伊甸／绝妖星全部缺圈问题已修复。若仍无提示，请保留发生时间、技能名及该次 `dalamud.log`。
