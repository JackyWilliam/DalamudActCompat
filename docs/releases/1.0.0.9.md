# v1.0.0.9

## 本次更新

- **人多的战斗不再严重掉帧**（玩家反馈）：开着 DACT 打团队本、博兹雅的 CE 和旗舰时掉帧很严重，旗舰只有 2 帧，关掉重启后恢复一阵，周围人少时没有问题。原因是每一次技能命中 DACT 都会重新整理一遍整场战斗的数据，周围人越多、打得越久，这一遍就越慢，最后拖住了游戏画面。
  - 战斗中的数据改为最多每 0.1 秒整理一次。开打的第一下仍然立即显示，战斗结束时的数据照常是完整的，榜单看不出差别。
  - 整理数据时不再反复生成大量临时内容，也不再每次把所有人的全部命中重看一遍。
  - 同一个压力测试（周围 120 人、每秒 1000 次命中）里，处理一次命中的耗时降到原来的约三十分之一，占用的临时内存降到原来的约千分之一。
- **横版榜单可以按窗口宽度收窄**（玩家建议）：以前每名玩家的格子宽度是固定的，想看全队只能把窗口拉长。现在可以在「战斗统计 → 榜单模板 → 自定义… → 横版 → 窗口外观」打开「窗口放不下时收窄模块」：
  - 窗口放不下所有玩家时，每名玩家的格子平均收窄到刚好放下，最宽不超过「模块宽度」。
  - 收窄后优先保证数字显示完整，位置不够时名称会缩短或不显示。
  - 窗口窄到看不清时停在最小宽度，仍然可以左右滑动。
  - 这个开关默认关闭，已经调好的横版布局不会变。
- **横版的全队总伤害、总治疗不再随窗口拉长**（玩家建议）：以前它们平分整个窗口，名称在最左、数字在最右。现在每一项最宽为一个玩家格子的宽度，从左边排起。竖版和职能分栏榜单不变。
- **导入还没适配的仿生石新版时会说明原因**：仿生石（Simulant）上游在 11 月 14 日发布了 v0.1.0.0，它重写了防火墙和卸载流程，并要求鲶鱼精邮差 1.3.6.7 以上，DACT 还没有适配。以前导入后只显示一句看不懂的英文错误，现在会说明原因，并提示重新导入 v0.0.4.2。

## 已知情况

- 掉帧的修复是用压力测试验证的，还没有在游戏里实测。更新后如果人多时仍然卡，请在 DACT 里点「反馈」提交，会自动带上诊断信息。
- 仿生石 v0.1.0.0 尚未适配，请继续使用 v0.0.4.2。
- 其它绝本（巴哈姆特、亚历山大、龙诗、欧米茄）的开荒进度阶段仍按「主要 Boss 换了名字」来数，可能和 FFLogs 的阶段不一致；光暗未来和绝神兵已按 FFLogs。

## 使用说明

通过原插件订阅更新至 1.0.0.9，更新后请完整重启游戏。配置、好友和云备份都不受影响。第一次启动 1.0.0.9 时会下载一次同版本的 Host。

## 验证范围

Release 构建、Scanner、包冒烟、Host 冒烟与各项触发器回归通过。新增的检查：人多场景的压力测试（周围 120 人、每秒 1000 次命中，按真实节奏持续 3 秒），核对数据整理次数被合并、每次命中占用的临时内存有上限、战斗中和结束时的数据都完整、最高伤害与逐条重算一致，并逐条对照玩家名字的匹配规则没有变化；横版榜单的格子宽度与全队合计宽度的计算、开关默认关闭、旧配置不变、备份恢复后保留；用真实界面库绘制横版榜单 20 种布局（开关、两种字号、五种窗口宽度）并出图检查。原有 288 种竖版与职能分栏布局、48 组收起动画的检查通过。仿生石版本提示的检查：v0.1.0.0 等更高版本不加载并给出说明，v0.0.4.2 及更早版本不受影响。
