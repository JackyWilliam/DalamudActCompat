# v1.0.0.1

## 本次更新

- **修复界面抖动**：游戏的界面缩放不是整倍数时（卫月默认字号就是这种情况），登录 / 注册 / 找回密码页和 Discord 绑定页的表单会一直上下抖动；好友聊天的输入区和消息列表也会跟着抖。现在这些位置都对齐到整像素，不再抖动。
- **开屏动画可设置**：设置 → 通用 → 开屏动画，可选「每次启动游戏后首次打开时播放」（默认，与 1.0.0.0 相同）、「每次打开控制中心都播放」或「关闭」。播放时点一下仍可跳过。
- **翻译补全**：全局搜索的 31 个条目和战斗记录的 1 条悬停提示补上繁体中文、日语、德语、法语译文，非简体中文界面不再夹杂英文。

## 使用说明

通过原插件订阅更新至 1.0.0.1，更新后请完整重启游戏。这次不需要重新登录。

## 验证范围

Release 构建、完整包冒烟测试通过；账号原生界面测试新增 100%–140% 多种缩放和逐像素窗口高度下的「表单不再移动」检查，以及开屏动画三种模式的检查。全部窗口和页面在 94%、106%、118%、125%、150% 缩放下逐帧比对，除本来就在播放的动画外没有持续移动的界面。
