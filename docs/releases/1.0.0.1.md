# v1.0.0.1

## 本次更新

- **修复界面抖动**：游戏的界面缩放不是整倍数时（卫月默认字号就是这种情况），登录 / 注册 / 找回密码页和 Discord 绑定页的表单会一直上下抖动；好友聊天的输入区和消息列表也会跟着抖。现在这些位置都对齐到整像素，不再抖动。
- **开屏动画可设置**：设置 → 通用 → 开屏动画，可选「每次启动游戏后首次打开时播放」（默认，与 1.0.0.0 相同）、「每次打开控制中心都播放」或「关闭」。播放时点一下仍可跳过。
- **修复更新到 1.0 后 Triggernometry 显示「故障」**：1.0.0.0 首次启动要另外下载配套的 Host 组件，下载失败时（GitHub 故障、网络连不上）会退回用旧版本留下的 Host，旧 Host 认不出 Triggernometry 2.4.3.0，于是加载失败。现在 Host 直接随插件本体安装，和插件版本始终一致，不再单独下载，也不会再退回旧版。
- **Triggernometry 以后更新更稳**：DACT 给 Triggernometry 加的绘图诊断如果对不上它将来的新版本，只会关掉这项诊断，Triggernometry 照常加载，不再整个显示「故障」。
- **翻译补全**：全局搜索的 31 个条目和战斗记录的 1 条悬停提示补上繁体中文、日语、德语、法语译文，非简体中文界面不再夹杂英文。

## 使用说明

通过原插件订阅更新至 1.0.0.1，更新后请完整重启游戏。这次不需要重新登录。

插件本体因为带上了 Host，从约 31 MiB 变成约 42 MiB；Cactbot 和随包扩展仍是单独的资源包，同一份内容不会重复下载。

## 验证范围

Release 构建、完整包冒烟测试与 Host 冒烟测试通过；发布脚本校验插件本体内含 Host、资源清单不再列出 Host 包，并新增「缓存里有旧版 Host 包且下载全部失败时，仍使用本体自带 Host」的检查；Host 冒烟新增模拟 Triggernometry 签名变化的检查；账号原生界面测试新增 100%–140% 多种缩放和逐像素窗口高度下的「表单不再移动」检查，以及开屏动画三种模式的检查。全部窗口和页面在 94%、106%、118%、125%、150% 缩放下逐帧比对，除本来就在播放的动画外没有持续移动的界面。
