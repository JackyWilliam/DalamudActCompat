# v0.4.5.16

## 本次更新

- 宝宝椅（Triggernometry）：修复电脑系统时间与游戏服务器不一致时，触发器“延迟一段时间再播报或再判断”的动作被提前执行的问题。电脑时钟快了几秒时，部分机制会出现方向播报相反（例如 M12S 喋血的左右半场）、提示提前（例如点名标记）或漏报（例如 M12S 末期的左右扇形）。该问题自 0.4.5.14 起出现；电脑时间准确的用户不受影响。
- 修复电脑时钟偏快时，Host 启动期间收到的战斗日志被全部当作过期丢弃的问题。

## 使用说明

通过原插件订阅更新至 0.4.5.16，更新后完整重启游戏。
建议在 Windows「设置 → 时间和语言 → 日期和时间」中点击「立即同步」校准一次系统时间；更新后即使电脑时间仍有偏差，触发器延迟也会按实际经过的时间执行。
