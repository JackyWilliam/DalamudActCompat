# v1.0.1.0

## 本次更新

- **新增 FFLogs 日志上传**（最初的实现由 ACTLogsUploader 的作者 zhui-zi 贡献）：不用另开 FFLogs 上传器，在 DACT 里就能把战斗日志传到 FFLogs。
  - 侧栏新增「FFLogs」页。用 FFLogs 网站账号登录后，点「上传最新日志」上传整份日志，或点「选择战斗…」只传其中几场。
  - 「实时上传」：打本时每场战斗结束会自动传到同一份报告。
  - 「战斗记录」里每场战斗多了「上传到 FFLogs」，可以只传这一场。
  - 「上传设置」里选报告的可见性、区域、公会和描述，也可以设置启动后自动登录、自动开始实时上传。
  - 解析和上传在独立的辅助进程里进行，不在游戏进程里。第一次使用时会下载约 15 MB 的解析引擎（微软官方的 V8 运行库，按哈希校验），之后不用再下。
  - 密码只在打开「记住密码」时保存，加密后只留在这台电脑上。
- **Parse 预估搬到「FFLogs」页**：原来在「战斗统计」页的 FFLogs 在线估算，现在和日志上传放在一起。功能不变，已经填好的 Client ID 和 Secret 不用重填。
- **「战斗统计」页重新排版**：榜单模板改成三张带预览的卡片，点「自定义布局…」调整样式；原有的设置项都还在。
- **好友来信提示音可以调音量**（玩家建议）：「好友 → 来信提醒」的提示音下面多了音量滑块，只调这个提示音，不影响游戏音量。

## 已知情况

- 日志上传的各个入口在自动测试里用模拟的 FFLogs 站点核对过。游戏里实际验证了登录、解析引擎的下载与启动、读取当天日志，**还没有用真实战斗完整上传过一次**。遇到上传失败或报告不对，请在 DACT 里点「反馈」，写上是哪个入口、提示了什么。
- 游戏里的验证只在国服站点（cn.fflogs.com）上做过。
- 上传用的是 FFLogs 桌面上传器的接口。FFLogs 以后提高上传器的版本要求时，上传会暂时失效，需要等 DACT 更新。
- 解析引擎先从 NuGet 官方源下载，失败时改用国内镜像。下载没成功的话，再点一次上传会重新下载。

## 使用说明

通过原插件订阅更新至 1.0.1.0，更新后请完整重启游戏。配置、好友和云备份都不受影响。第一次启动 1.0.1.0 时会下载一次同版本的 Host 和随包 ACT 插件。

## 验证范围

Release 构建、Scanner、包冒烟、Host 冒烟与各项触发器回归通过。新增的检查：FFLogs 日志上传（解析引擎包的校验与安装、辅助进程、登录、上传设置、整份 / 选场 / 单场上传、没有战斗的日志不建报告、取消、实时上传启停、退出登录、随游戏进程退出）；好友提示音音量（旧配置保持原来的响度、设置保存与读取、音量换算）；繁中、日语、德语、法语的词条齐全、占位符一致；中文、德语、日语界面截图核对。
