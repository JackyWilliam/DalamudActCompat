# v0.4.5.0

## 本次更新

- 好友列表新增右键设置、修改和清除备注。备注会随 DACT 账号自动同步，换电脑后可继续使用；好友列表、聊天和消息提醒保留原账号名以便辨认。
- 修复 Cactbot 设置窗口无法选择 user 目录的问题，支持浏览或直接输入自定义路径；自定义目录中的脚本、时间轴及配置可随加密云备份恢复。
- 战斗统计新增“DACT默认”和“脱战自定义秒数重置”。默认保留此前行为，选择脱战重置后可自行输入等待秒数。
- “艾欧泽亚”皮肤调整为赞助 3 级及以上解锁；1、2 级的赞助图标和红色名字保留。
- 更新抹茶的动态事件、FATE、副本及世界数据，修正抹茶和银山雀儿的 FATE 适配，以及抹茶的跨服排队事件适配。
- 修复扩展 DLL 未变化时数据包升级被漏过的问题，扩展更新保留原来的启用或禁用状态。

## 使用说明

- 备注最多 40 字，支持留空清除；两台设备同时修改时会提示重新编辑，避免覆盖另一台设备的新备注。
- 脱战重置只分段战斗统计，原有触发器、邮差等扩展的战斗事件流程保持。
- 自定义 Cactbot 目录在本机保留；换电脑恢复配置时使用该电脑设置的目录，不照搬另一台电脑的盘符。
- 更新后请完整重启游戏，以加载本次配套解析组件与扩展资源。
