# v0.4.5.20

## 本次更新

- 适配 Triggernometry 2.4.3.0：中文维护版 2.4.3.0 为了能取消已排队的动作，调整了动作执行入口的参数。DACT 的兼容改写因此失配，Triggernometry 无法加载，扩展页“打开配置”没有反应。现已兼容，随包 Triggernometry 同步更新至 2.4.3.0。

## 使用说明

通过原插件订阅更新至 0.4.5.20，更新后完整重启游戏。
已通过扩展更新器装上 Triggernometry 2.4.3.0 的用户，更新后触发器会恢复加载；仍为 2.4.1.1 的用户可继续使用，也会在确认随包更新后切换到 2.4.3.0。

## 验证范围

兼容改写在 Triggernometry 2.4.1.1 与 2.4.3.0 上都通过 Host 与进程内两条改写路径和 IL 静态校验；CI 使用真实的 2.4.3.0 运行 Host、U7b 初始化顺序、事件时间基准、绘图诊断与清特效链回放。

Triggernometry 2.4.3.0 自身的功能与语义变化（例如新增的“终止本次触发中的全部动作”、打断已排队动作的范围）由上游维护，本版只保证它在 DACT 中加载、打开配置并沿用既有兼容桥接。触发器包的实战表现仍以更新后的实际使用为准。
