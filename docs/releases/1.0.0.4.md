# v1.0.0.4

## 本次更新

- **适配 7.58（国服 / 国际服）**：游戏更新到 7.58 后，1.0.0.3 的 ACT 解析器会在启动时报「No supported zone receive signature」，战斗统计、战斗记录、日志和宝宝椅等依赖解析器的功能全部没有数据。本版本让解析器认出 7.58 客户端，恢复正常解析。
- **同步上游 7.58 数据**：IINACT 2.10.3.12、OverlayPlugin 0.19.112（含 7.58 操作码与倒计时包结构）、7.58 网络事件表；抹茶和银山雀儿的事件映射也更新到 7.58。
- **修复「解析器故障：OverlayPlugin WebSocket server could not be started」**：悬浮窗配置文件存在、但里面没有 WebSocket 地址时（玩家反馈），解析器会整个启动失败，战斗统计和悬浮窗都不可用，重启也没用。现在会自动改回默认的 127.0.0.1:10501；自己设置过的地址（包括允许局域网访问）和端口不受影响。

## 已知情况

- 7.58 的官方解混淆配置（Unscrambler.XIV）还没有发布。本版本与上游 IINACT 2.10.3.12 一样，先用运行时兼容方式，启动时会弹出「ACT 网络兼容性警告」。战斗解析正常；但在官方配置发布并核对之前，新日志的 FF Logs 排名有效性暂不作保证。
- 7.58 的 FATE 与跨服排队数据包编号还没有公开值，为避免把无关数据当成 FATE，本版本暂不解析：抹茶的 FATE 提醒、跨服排队提示，以及银山雀儿依赖 FATE 的功能暂时不可用，等上游公开后恢复。

## 使用说明

通过原插件订阅更新至 1.0.0.4，更新后请完整重启游戏。这次不需要重新登录，配置、好友和云备份都不受影响。第一次启动 1.0.0.4 时会下载一次同版本的 Host。

## 验证范围

Release 构建、Scanner、包冒烟与 Host 冒烟测试通过。新增 7.58 检查：接收签名在 7.58 版本号下使用 7.57 调用点并拒绝旧签名（本机国服 7.58 客户端离线扫描：两种调用点各 3 处、指向同一接收函数）；三地区 Machina、OverlayPlugin 7.58 操作码；7.58 没有官方解混淆配置时走兜底，且兜底解混淆能完整还原合成的 ActorCast / ActionEffect 包；抹茶两地区 7.58 映射、钓鱼流程与旧 FATE 编号不再被识别；银山雀儿 7.58 映射。另新增悬浮窗配置检查：缺少、为空或无法解析的 WebSocket 地址与端口会修复为默认值，通配地址与自定义地址保持不变。
