# v1.0.0.4

## 本次更新

- **适配 7.58（国服 / 国际服）**：游戏更新到 7.58 后，1.0.0.3 的 ACT 解析器会在启动时报「No supported zone receive signature」，战斗统计、战斗记录、日志和宝宝椅等依赖解析器的功能全部没有数据。本版本让解析器认出 7.58 客户端，恢复正常解析。
- **同步上游 7.58 数据**：IINACT 2.10.3.12、OverlayPlugin 0.19.112（含 7.58 操作码与倒计时包结构）、7.58 网络事件表；抹茶和银山雀儿的事件映射也更新到 7.58。
- **修复「解析器故障：OverlayPlugin WebSocket server could not be started」**：悬浮窗配置文件存在、但里面没有 WebSocket 地址时（玩家反馈），解析器会整个启动失败，战斗统计和悬浮窗都不可用，重启也没用。现在会自动改回默认的 127.0.0.1:10501；自己设置过的地址（包括允许局域网访问）和端口不受影响。
- **修复宝宝椅读到旧的实体数据、播报方位出错**（玩家反馈：绝妖星宝宝椅机制报反，如 P1 一神击退）：触发器在连线日志到达的那一刻读取连线来源的位置，来判断谁被点名击退。DACT 以前会在实体数据同步到位之前就把这条日志交给宝宝椅，位置刚变化或刚出现的实体会被读成旧值或读不到，被点名的人就听到了另一组的方位（正好是对角）。现在每条日志都会等「在它之后采集的那份实体数据」到达，再交给宝宝椅；通常只多等一两帧，最长 150 毫秒，等不到就照常放行。
- **修复好友页面一直「正在读取状态…」、看不到好友**（玩家反馈）：把 DACT 配置带到另一台电脑或另一个 Windows 账号后（例如网吧、重装系统），本机保存的聊天暂存文件在新环境里解不开，好友列表会一直卡在读取。现在会把这个文件另存为 `.unreadable`（不删除）并重新开始，好友、状态和聊天恢复可用，同时提示一次；当时还没确认发出的消息请以聊天记录为准。

## 已知情况

- 7.58 的官方解混淆配置（Unscrambler.XIV）还没有发布。本版本与上游 IINACT 2.10.3.12 一样，先用运行时兼容方式，启动时会弹出「ACT 网络兼容性警告」。战斗解析正常；但在官方配置发布并核对之前，新日志的 FF Logs 排名有效性暂不作保证。
- 击退报反的修复覆盖的是「日志比实体数据先到」；如果一个新出现的实体超过 200 毫秒还没同步过来，日志仍会像以前一样放行。这类修复都只做了离线验证，实际副本里的表现需要游戏内确认。
- 7.58 的 FATE 与跨服排队数据包编号还没有公开值，为避免把无关数据当成 FATE，本版本暂不解析：抹茶的 FATE 提醒、跨服排队提示，以及银山雀儿依赖 FATE 的功能暂时不可用，等上游公开后恢复。

## 使用说明

通过原插件订阅更新至 1.0.0.4，更新后请完整重启游戏。这次不需要重新登录，配置、好友和云备份都不受影响。第一次启动 1.0.0.4 时会下载一次同版本的 Host。

## 验证范围

Release 构建、Scanner、包冒烟与 Host 冒烟测试通过。新增 7.58 检查：接收签名在 7.58 版本号下使用 7.57 调用点并拒绝旧签名（本机国服 7.58 客户端离线扫描：两种调用点各 3 处、指向同一接收函数）；三地区 Machina、OverlayPlugin 7.58 操作码；7.58 没有官方解混淆配置时走兜底，且兜底解混淆能完整还原合成的 ActorCast / ActionEffect 包；抹茶两地区 7.58 映射、钓鱼流程与旧 FATE 编号不再被识别；银山雀儿 7.58 映射。另用真实宝宝椅引擎和 U7b v1.0.6 原版触发器复现了「一神击退报反」：连线来源刚移动、刚出现或离开后又回来时，修复前播报「直接去右上分散」，修复后为「点名击退」「击退到左下分散」；用无法解密的聊天暂存文件复现了好友页卡在读取，修复后好友、状态、聊天与发送均正常，原文件保留。新增悬浮窗配置检查：缺少、为空或无法解析的 WebSocket 地址与端口会修复为默认值，通配地址与自定义地址保持不变。
