# v1.0.0.6

## 本次更新

- **修复开着加速器时 AI 助手用不了**（玩家反馈，多见于在海外用网易 UU 等加速器玩国服）：只要开着加速器，用 Claude、ChatGPT 等国外服务的 AI 助手就一直连不上，关掉加速器才正常。原因是这类加速器会把游戏进程的所有网络连接都转到自己的线路上，而 DACT 以前在游戏进程里发 AI 请求，请求被一起带到了服务商不支持的地区。现在 AI 请求改由 DACT 自带的一个独立小进程发出，不再被加速器转走，开着加速器也能正常使用，不用再切换加速模式。
  - 这个进程只负责转发 AI 请求，不加载任何 ACT 扩展；API Key 仍然只在本机使用，DACT 服务器看不到。
  - 它和以前一样跟随系统代理与「接口地址」设置，国内用代理或中转地址的用法不受影响。
- **AI 报错更准确**：服务商按地区拒绝请求时，以前会显示「这个 Key 没有权限使用该模型或接口」，让人误以为 Key 坏了。现在会直接说明是网络出口地区不被支持，并给出处理办法；其它权限问题会附上服务商的原话。
- **「脱战隐藏」可以延时**（玩家许愿）：打开「脱战隐藏」后可以选择脱战后多久再隐藏——立即、10 秒后、30 秒后、1 分钟后或 2 分钟后，方便看完上一场；倒计时内重新进入战斗会一直显示。悬浮窗在「悬浮窗」页的「隐藏时机」里设置，战斗统计在「自定义…」顶部「脱战隐藏」旁边设置。默认仍是脱战立即隐藏。

- **恢复云端备份时保留本机的「游戏区域」**：在「设置」里手动选过「国服 / 国际服」的玩家，以前在另一台电脑或另一个客户端（例如国服备份恢复到国际服）恢复云端配置时，会连这个手动选择一起带过去，使解析器按错误的区域工作。现在恢复时和日志目录一样保留本机原来的选择；本机还没有配置时恢复为「自动检测」。

## 已知情况

- AI 请求需要 DACT 的配套组件（Host）。第一次启动下载 Host 失败时，AI 会暂时照旧从游戏里直接发送，此时开着加速器仍可能连不上；按「核心组件」窗口提示重新下载即可。
- 7.58 的 FATE 与跨服排队数据包编号仍没有公开值：抹茶的 FATE 提醒、跨服排队提示，以及银山雀儿依赖 FATE 的功能继续暂不可用。

## 使用说明

通过原插件订阅更新至 1.0.0.6，更新后请完整重启游戏。配置、好友和云备份都不受影响。第一次启动 1.0.0.6 时会下载一次同版本的 Host。

## 验证范围

Release 构建、Scanner、包冒烟与 Host 冒烟测试通过。新增 AI 中转检查：用真实 Host 与本机模拟的服务商核对请求确实从独立进程发出（按连接所属进程判断）、5 MiB 请求原样往返、Claude 官方 SDK 也走中转、取消请求会中断上游、游戏退出后中转随之退出、缺少 Host 时退回直连；OpenAI 与 Anthropic 的地区拒绝和普通权限错误各自显示正确文案。新增脱战隐藏延时检查：默认立即隐藏、延时内显示、重新进战取消、上限与旧配置迁移。开发者本机开着网易 UU 加速器实测 AI 助手正常、日志确认请求由中转进程发出，脱战隐藏延时生效；新的「隐藏时机」选项样式以中、德、日、法四种语言出图核对。
