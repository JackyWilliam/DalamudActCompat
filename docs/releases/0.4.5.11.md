# v0.4.5.11

## 本次更新

- 修复后台已经解封，客户端重启后仍显示“禁用”、无法重新登录的问题。
- 账号安全提示新增“重新验证解封”入口。旧登录已失效或丢失时，可输入用户名和密码重新向服务器确认账号及当前机器的状态。
- 关闭提示后，可使用 `/dact` 或插件设置重新打开验证窗口。
- 修复旧状态检查的延迟响应可能重新写回已解除封禁标记的问题。
- 验证只用于确认解封，不会更换共用登录、覆盖恢复密钥或自动重启已停止的组件。仍有账号、机器或连坐封禁时保持限制。

## 更新与恢复

1. 从原插件订阅更新至 0.4.5.11，并完整重启游戏。
2. 如果管理员已解封但仍显示禁用，在“账号安全”窗口输入用户名和密码，点击“重新验证解封”。
3. 提示已解除后，重载 DACT 或完整重启游戏，再正常登录。

本次保留原配置、云备份及六绝皮肤权益，无需更换订阅链接。
