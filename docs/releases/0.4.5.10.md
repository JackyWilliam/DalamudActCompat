# v0.4.5.10

## 本次更新

- 新增六款绝本主题皮肤：巴哈姆特、究极神兵、亚历山大、幻想龙诗、欧米茄、光暗未来。沿用 DACT 横向布局，并为标题、页签、按钮、卡片和好友抽屉加入对应主题细节。
- 通关任意一个绝本，即可为当前 DACT 账号永久解锁全部六款，无需分别通关六个绝本。
- 解锁状态随账号云同步。同一 DACT 账号登录后，游戏开始和选角界面也能使用；换设备登录后自动恢复解锁资格。
- 解锁记录独立保存，恢复旧配置、回滚备份或重置密码不会清除已获得的资格。网络暂时中断时先在本机解锁，并自动重试同步。
- 完善账号切换与同步响应隔离，避免退出登录后仍显示其他账号的解锁状态。

## 更新与解锁说明

- 通过原插件订阅更新至 0.4.5.10，并完整重启游戏；原有配置继续保留。
- 更新后首次请登录 DACT，并进入一次已通关任意绝本的角色，以确认并同步资格。之后同一账号无需再次进入该角色即可使用六款皮肤。
- 在 DACT 的皮肤设置中选择对应主题。未通关的用户仍可使用原有符合条件的皮肤。
- 多设备请一并更新至 0.4.5.10。旧版不识别六绝皮肤，恢复新配置时可能将皮肤选择改回默认，但不会清除账号的永久解锁资格。
