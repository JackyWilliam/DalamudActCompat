# v0.4.5.7

## 本次更新

- 统一管理 Cactbot 文字提醒、时间轴、HTML 模板和自定义网址悬浮窗，使用同一列表及常规、快捷键、来源设置页。
- 保留独立的 Cactbot 设置、解析器与资源状态、安装/更新、官方项目及异常处理入口，并改善窄窗口和多语言排版。
- 新增每个悬浮窗独立的全局快捷键，可切换显示/隐藏、开启/关闭、鼠标穿透和位置锁定，支持录制、启停、删除及冲突提示。
- 修复多款纯色皮肤中首页及其他按钮与卡片背景同色的问题，区分普通、悬停、按下和已打开状态。
- 修复部分自定义网页在自动补全路由后无法连接解析器的问题；原网址可继续使用，更新后重新打开悬浮窗即可。
- 隔离单个动态图形刷新异常，避免其阻断其他图形刷新和过期清理，改善连续战斗中的绘图稳定性。

## 更新说明

- 请通过原插件订阅更新，并完整重启游戏以加载新版本。
- 悬浮窗原有网址、位置、大小和显示设置继续保留；修改来源或重新检测连接时保留独立的手动隐藏及启动偏好。
- 快捷键在各悬浮窗的“快捷键”页设置；系统或其他程序占用的组合键会显示冲突提示。
