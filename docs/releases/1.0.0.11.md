# v1.0.0.11

## 本次更新

- **开荒进度的阶段不再乱跳**（玩家反馈：绝亚显示「最远 P8」，绝神兵刚见泰坦就显示 P5）：以前只有光暗未来和绝神兵有自己的阶段表，其它副本按「场上血量最高的敌人换了名字」来数阶段。两个 Boss 同场时，谁暂时选不中就轮到另一个当最大目标，每轮多数一个阶段；后面阶段回场的 Boss 也会再数一次。
  - 七个绝本现在都按各自的阶段表来数：绝巴哈、绝神兵、绝亚、绝龙诗、绝欧米茄、光暗未来、绝妖星。只有该阶段自己的 Boss 可以选中时才进入下一阶段，转场算在前一个阶段里。
  - 绝亚是 P1 有生命活水、P2 残暴正义号与巡航驱逐者、P3 至尊亚历山大、P4 完美亚历山大，和 FFLogs 一致。
  - 绝欧米茄的 P4（蓝屏）和绝妖星的 P2、P5 与前一阶段是同一个名字的 Boss，靠 Boss 的血条重新回满来识别。
  - 其它副本（零式、极神等）：同场一起打的敌人互相换位不再算新阶段；Boss 离场后才出现的小怪、Boss 回场仍然各算一个阶段。
  - 以前记下的记录会在更新后自动按新规则改正，不需要清数据。例如反馈里那一把绝亚，会从 P8 变成 P3。

## 已知情况

- 这次改动只在自动测试里按各副本的流程核对过，还没有在游戏里实打验证。阶段不对时请在 DACT 里点「反馈」，写上是哪个副本、打到哪里、显示成了第几阶段。
- 除绝亚外，其它绝本的阶段划分依据的是攻略资料和 Cactbot 时间轴的阶段结构，没有逐一拿 FFLogs 的阶段列表核对。
- 绝欧米茄 P4、绝妖星 P2 / P5：如果前一阶段结束时 Boss 的血量还在一半以上，会继续显示成前一阶段；旧记录只记了 Boss 的名字，这三个阶段无法恢复。
- 绝龙诗在 P4 之后如果营救失败、回到 P2 重新打，会显示成 P5。
- 没有专属阶段表的副本里，下一阶段的 Boss 如果和上一阶段的敌人同场超过 10 秒，不再单独算一个阶段。

## 使用说明

通过原插件订阅更新至 1.0.0.11，更新后请完整重启游戏。配置、好友和云备份都不受影响。第一次启动 1.0.0.11 时会下载一次同版本的 Host 和随包 ACT 插件。

## 验证范围

Release 构建、Scanner、包冒烟、Host 冒烟与各项触发器回归通过。新增或扩充的检查：七个绝本逐步核对阶段推进（转场、分身和小怪、同场的两个 Boss、回场和血条回满的 Boss）；旧记录更正（反馈里的绝亚记录由 P8 改为 P3，P1 团灭的记录改回 P1，其它语言客户端记下的记录保持不变）；血条回满与小幅回血的区分；通用规则的六种情况（同场换位、离场后的小怪、短暂交叠、卡顿间隔、名字稳定时间、最短阶段时长）。
