# v1.0.1.2

## 本次更新

- **战斗统计窗口可以给文字描边**（玩家反馈）：底板全透明时，统计窗口的字直接叠在游戏画面上，碰到雪地、天空这类亮背景就看不清。现在可以给文字加一圈边，亮字配深色边，在任何背景上都能看清。
  - 位置：「战斗统计」页点「自定义布局…」，右侧「窗口外观」最下面的「文字描边」。
  - 默认关闭，不打开的话和以前完全一样。经典榜、横版、职能分栏各自保存。
- **战斗统计窗口可以自选文字颜色**（玩家反馈）：同一个位置的「文字颜色」。改的是名字和普通文字，标签的灰色会跟着变；冰蓝的数值、金色的自己这些强调色不变。点「恢复自动文字颜色」回到原来的颜色。
- **战斗记录里副本和野外分开计数**（玩家反馈）：以前副本和野外共用一个「历史记录上限」，清一圈野怪或刷一阵 FATE 就会把副本记录顶掉。现在两类各保留「历史记录上限」条，互不挤占；每场战斗的日志文件也跟着各自的记录保留。
- **近期战斗可以筛选**（玩家反馈）：「战斗记录」页的列表上方多了「全部 / 副本 / 野外」，会记住上次选的。
- **连着打的野外战斗会收成一个文件夹**（玩家反馈）：同一张地图里连着打的野外战斗（间隔不超过 30 分钟，中间没有进本）收成一行，以地图命名，点开看每一场。博兹雅、优雷卡这类大型野外任务仍然算副本。
- **帮助页的截图更新到了这一版**：「悬浮窗」页那张图上有「WebSocket 地址」按钮了。

## 已知情况

- 这一版的改动经过了自动测试和截图核对，**没有在游戏里实际验证过**。描边的粗细和浓度是照着截图定的，觉得太重或太轻，或者战斗记录的折叠和筛选不对，请在 DACT 里点「反馈」。
- 文字描边打开后，每段文字会多画四遍。24 人、48 人场景下没有实测过帧率，觉得掉帧可以先关掉描边。
- 自选文字颜色不会改数值的强调色。想连数值一起换颜色的话，请在「反馈」里告诉我。
- FFLogs 日志上传仍然没有用真实战斗完整上传验证过，情况同 1.0.1.0。

## 使用说明

通过原插件订阅更新至 1.0.1.2，更新后请完整重启游戏。配置、好友和云备份都不受影响，已有的战斗记录不需要迁移，升级时不会多删任何一条。

## 验证范围

Release 构建、Scanner、包冒烟、Host 冒烟与各项触发器回归通过。新增的检查：战斗记录分开计数、日志文件跟随记录、野外折叠规则和三种筛选；「战斗记录」页在 15 款皮肤、六种语言、两种宽度、三档字号下的排版；统计窗口的文字描边和自选颜色在经典榜、横版、职能分栏上的绘制（打开只增加描边、关闭后与原来完全一致、不会影响到另一个统计窗口）；旧配置读入后保持原样；繁中、日语、德语、法语的词条齐全、占位符一致。
