# v0.4.4.4

## 游戏解析范围

- 在「概览 → 基础设置」新增「游戏解析范围」，支持所有人、仅自己、小队成员、团队成员四档，默认保持所有人。
- 小队成员指自己所在的小队，团队成员包含其他小队；支持24人团队中不同的A、B、C队归属，召唤物按主人归属统计。
- 切换后立即作用于后续统计，无需重启解析器，已经记录的数据保留。
- 解析器、伤害补算、治疗、死亡观测和DPS计时使用一致的范围，避免被排除的队员重新进入统计或拉长计时。
- 解析范围随配置保存和云同步恢复；原始日志继续完整输出，原有触发器保持可用。

## 更新说明

使用原卫月订阅正常更新，更新后请完整重启游戏。现有配置和已发现皮肤均保留。

仍安装错误编号 `4.4.0.0` 的用户，请先用同一仓库中的 **DACT 修复工具** 修复到 `0.4.4.0`，完整重启后再更新到 `0.4.4.4`；无需重置配置。
