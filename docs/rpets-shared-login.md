# RPets 共用登录（本地试用配套）

DACT 0.4.1.0 在完整好友功能基础上加入 RPets 共用登录，服务器接口不变。RPets 作为独立插件安装。

同一卫月配置目录的 `pluginConfigs/Raynording.Account/session.dat` 保存 DPAPI 加密会话、持久登录偏好及递增修订号。任一插件登录、切号或退出后，另一个插件约一秒内发现变更，并在服务器验证令牌及账号名称后启用。过期、撤销、封禁仍由现有服务器判断；不共享明文密码。

`SharedAccountStore.cs` 与 RPets 内的副本保持字节一致。命名互斥锁和原子文件替换保证两插件不会同时覆盖，发布须匹配请求开始时的修订号，旧登录结果无法覆盖较新的退出/切号。退出使用明确空会话标记，不能把删除文件当作重新导入旧凭据的许可。未记住登录时，只有同一游戏 PID 和启动时间可恢复共享会话。

旧 DACT 自动登录会在服务端验证后迁移；旧凭据格式继续兼容恢复密钥/备份。共享导入仍调用原备份与邀请接口；不会改变原好友聊天、20/3 保留、通知、状态或其他解析功能。

验证：完整 Package/FFXIV_ACT_Plugin 回归；RPets 测试工程通过外部项目别名引用实际 DACT 客户端，两边使用隔离配置和模拟服务验证 RPets 先启动旧凭据迁移、双向登录/退出、不记住登录、迟到登录和服务器拒绝令牌。实际游戏双插件加载仍须用户验收。
