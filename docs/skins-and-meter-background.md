# 皮肤与统计背景

设置与账号页顶部的「外观与皮肤 → 管理皮肤」提供默认外观、账号赞助皮肤和探索配色。

## 预览与退出

- 卡片使用标题栏、标签、按钮组成的外观缩略图，右侧展示选中皮肤的大预览。窄窗口或大字体时改为下拉选择器，避免必须先滚过大图才能切换。
- 点击卡片只改变临时预览；「应用皮肤」才修改偏好并由主页面保存。仍可预览未获授权的赞助皮肤，但不能应用。未发现彩蛋只显示神秘插图，不泄露配色或名称。
- 底部固定「返回设置」「应用皮肤」。返回或 Esc 回到设置；标题栏关闭按钮隐藏主窗口；未应用的预览不会保存。已有弹窗或文字输入获得焦点时，皮肤页不抢占 Esc。
- 切换主标签、退出账号或关闭主窗口会离开皮肤页；下次打开从当前生效外观开始。

## 账号权益

- 三级及以上赞助解锁「艾欧泽亚」浅色皮肤。等级由独立管理后台手动设置，没有有效期。一级、二级仍保留赞助身份标识与红色名字。
- 当前已登录账号的 `auth/me` 或邀请摘要返回 `sponsor: { tier: 1 }`。旧服务端不返回该字段时按 0 级处理；管理员身份不会自动授予皮肤。
- 权益不存入本地配置或加密备份。切换账号、注销或封禁后回到默认外观，但保留偏好的皮肤 ID，以便重新登录获授权后恢复。
- 既有账号心跳同步等级，也可点击「刷新权益」。客户端皮肤属于本地显示偏好，不能将开源客户端显示门禁视为防篡改 DRM。
- 云账号页「支持 DACT」中的「爱发电支持」使用默认浏览器打开 `https://ifdian.net/a/raynor`。赞助后由管理员核对账号并设置等级；按钮本身不自动授予权益。

## 原版浅色素材

`GameSkinAssets` 通过 Dalamud `ITextureProvider.GetFromGame` 读取玩家本机 SqPack 的 `ui/uld/img01/`，优先 `_hr1.tex`，缺失时使用普通分辨率。插件包不包含导出的游戏素材。

- Character/Social 的 `TabButtonA`：88×26 切片，16 像素左右固定端帽，第二行含原版金色选中标记。
- `ButtonA`：100×28 原版按钮，保留左右端部；文字按实际字形边界在可见按钮面内居中，排除下方透明阴影。
- `WindowA_BgSelected_*`：九块窗口背景，中心与边缘按原尺寸平铺，避免放大纸张纹理。
- `WindowA_Button`、`CircleButtons`、`CheckBoxA`：关闭、帮助、设置图标和选择框；好友入口使用原版主菜单社交图标。
- 主标题栏 Logo 直接裁切为圆角，保留十次点击的探索命中区域。

文本仍由 Dalamud 当前字体渲染，DACT 页面内容及排列沿用自身功能布局。以上为原素材复用，不应表述为整个页面已经完成与游戏逐像素一致的验收；运行中游戏字体、缩放、悬停和焦点效果需要游戏可正常加载插件后对照。

## 探索配色（维护说明）

发现后显示皮肤名称并保存到常规配置；未发现时不在客户端透露具体步骤。

- 森之青玉：主界面左上角 Logo 连续点击 10 次。
- 月下紫晶：标题版本号连续点击 7 次。
- 暮光琥珀：同一次插件运行中访问全部六个主页面。
- 绯梦霓光：皮肤页「选择喜欢的外观」连续点击 5 次，保存 ID 仍为 `neon-pink`。
- 澄光流璃 / Lucent Glass：皮肤页顶部「设置与账号 / 外观与皮肤」连续点击 6 次，ID 为 `liquid-glass`。
- 无相玄墨 / Obsidian Void：皮肤页「点击卡片查看预览，应用后自动保存。」连续点击 7 次，ID 为 `obsidian`。
- 点击序列相邻间隔不超过三秒；同一皮肤只提示一次。恢复出厂设置会清除这些本地发现。
- 解锁不会自动应用，无赞助门槛。发现和所选皮肤随现有加密云备份保存、恢复；服务端不需要新增字段。

## 液态玻璃与纯黑材质

澄光流璃使用独立的 Direct3D 11 着色器。通过公开 `IUiBuilder.DeviceHandle` 获取设备，在 ImGui 绘制回调中复制当前面板背后的已绘制区域，再进行横纵两遍连续高斯模糊、圆角 SDF 遮罩、24px 边缘折射、2px 色散和指针高光。默认主窗叠加 56% 偏白底色，使用墨色文字，圆角为 14px；像素参数随字体缩放。主窗、标题、导航、按钮和皮肤预览共用该材质。标题操作组整体向内缩进 10px（随字体缩放），让关闭按钮的绘制和点击区域都避开玻璃边缘。

旧版间隔 3px 的 5×5 采样会遗漏细纹理，产生颗粒和条纹。现在按物理像素构建连续高斯核（默认 sigma=3，最高8），合并相邻像素的双线性采样，先完成模糊再折射，缩放时也不拉大采样间隙。临时纹理与采样纹理一起复用、释放；合成前恢复原输出目标和视口。

采样发生在正确的窗口层次，不使用旧帧截图；生产实现没有 CPU 像素回读、Present 钩子或游戏内存偏移。采样纹理按需增长并复用，切换离开皮肤/预览与卸载时释放；异常会记录一次并退回可读的普通材质。绘制结束恢复所有本次修改的 D3D11 状态，统计窗口仍在皮肤作用域之外。

无相玄墨的主画布为不透明 `#000000`，普通控件为近黑色，悬停、文字和强调色使用灰白层次。职业、状态和身份的语义配色维持原行为。

视觉参考为用户提供的 AutoTriadC 截图及 [Apple Liquid Glass 说明](https://developer.apple.com/documentation/TechnologyOverviews/liquid-glass)。[用户提供的订阅](https://raw.githubusercontent.com/extrant/DalamudPlugins/main/pluginmaster.json) 指向插件二进制分发；本实现没有复制该插件或 Apple 的代码。已验证真实 D3D11 材质行为，但尚未完成游戏实机与参考画面的逐像素一致验收。

## 统计背景

布局编辑器中每种模板独立设置 RGB 背景色和背景不透明度，职能分栏的两栏分别保存。提供恢复默认和完全透明按钮；选择颜色时，若原先完全透明，自动提高到 85% 以显示颜色。保存与取消沿用编辑器事务。

浅色且不透明度至少 65% 的背景使用深色文字。背景与客户端皮肤独立，职业配色不被替换。配置版本 16→17 时，将旧横版已被忽略的不透明度转为 0，保持用户升级前的透明外观；其他模板保留原值。

## 弹窗、底边与统计槽位

- 浅色皮肤的下拉列表、云同步状态和好友状态弹窗复用游戏窗口的金属边框；弹窗按实际内容自动调整高度，溢出时保留滚动。云同步状态增加关闭按钮，支持 Esc。
- 云同步状态弹窗的缩放内边距对齐整数像素，消除 16px 字体下约 0.12px 的虚假溢出和常驻滚动条；八款皮肤及四档字体回归覆盖此场景，长状态/小视口仍可滚动。
- 主页面与好友抽屉避开游戏素材底部的透明尾部，内容不再盖住下边框。布局编辑器按实际皮肤按钮高度预留底部操作区；保存、取消在字体缩放后仍保持可达，未保存退出确认沿用原有行为。
- 在布局编辑器添加槽位或更改「槽位内容」可选择「团队秒伤」。它与全队总伤害、总治疗一样显示在团队汇总区，不重复放在每名玩家行中，也不作为个人排序依据。
- 团队秒伤 = 当前战斗全队总伤害（含已归属的极限技）÷ 有效战斗秒数，显示整数；有效时长优先使用解析器的 CombatDuration，否则使用战斗起止时间，分母最少一秒。只显示自己、职能筛选不改变全队口径。
- 三种模板均可配置；职能分栏两栏独立保存。经典榜的固定 24 人紧凑布局及关闭汇总区的模式维持原规则。升级不自动插入可见槽位，不改变既有用户布局；新枚举值追加，兼容旧配置编号。

## 验证记录补充

- 弹窗原生验证覆盖 100%、140% 的边框、关闭、Esc、下拉选择和样式栈平衡；好友验证覆盖屏幕边缘、75%～200% 字体及长状态真实溢出。
- 三种编辑器模板在 880×590、85%／100%／140%／200% 字体下验证保存取消完整可见、保存一次及干净取消关闭。
- 团队秒伤验证全队共享时长、极限技、进行中战斗、清空及零时长，四份模板配置的克隆和序列化，以及旧枚举编号兼容。

- PackageSmoke 默认执行权限、配置迁移、序列化、发现和背景隔离验证。
- `--skins-only`：设置 `DACT_TEST_CIMGUI` 后执行真实 cimgui 离屏绘制、十次 Logo 点击、皮肤预览/应用/返回/Esc/关闭与未授权点击、编辑器保存/取消；可设 `DACT_TEST_GAME_SQPACK` 使用本机原版素材，`DACT_NATIVE_UI_OUTPUT` 输出预览。中英文及 760×520、140% 字体检查底部退出可达。
- `--liquid-glass-only`：使用本机 D3D11 硬件设备执行着色器编译、真实背景模糊、30组细条纹周期/方向/缩放去颗粒、白色半透底、增强折射/色散、中心保护、圆角/父级裁剪、悬停、淡出、视口偏移、输出目标及视口恢复、纹理复用及 GPU 时间测量，不加载真实游戏插件。
- 为 `--skins-only` 增加 `DACT_TEST_GPU_GLASS=1`，会将实际 cimgui 回调与真实 GPU 材质合成到测试背景上，输出两款皮肤的 PNG；棋盘是采样验证背景，不是皮肤纹理。
- `--friends-native-only` 同样设置 SqPack 和输出目录可额外输出浅色皮肤的真实好友抽屉截图；账号与消息来自隔离夹具，不连接实际好友服务。
- 额外绘制 85%、100%、140% 下的中文、英文及混合文字按钮；已有好友原生测试覆盖缩放、点击与焦点。
- `--skins-api-only` 由私有服务端合成测试夹具调用，验证真实 C# HTTP 账号切换、旧服务端和过期响应隔离。

发布需先部署服务端权益字段和管理入口，再发布客户端。皮肤逻辑不修改游戏热修兼容门禁；0.4.4.0 同时包含的解析更新详见 [7.56 热修依赖审计](bundled-plugin-audit-2026-09-17.md)。
