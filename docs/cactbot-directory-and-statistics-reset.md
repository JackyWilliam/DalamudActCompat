# Cactbot user 目录与统计重置

## Cactbot user 目录

在“悬浮窗 → Cactbot 设置”中选择 user 目录，会打开由该设置窗口持有的原生对话框。可以填写完整路径、浏览文件夹或恢复默认；取消保留原路径。选择目录不会自动搬移旧脚本，请将需要的文件放进所选目录。

自定义本地目录参与原有加密云备份，包括脚本、时间轴及其他资源。备份仍使用原来的 `DalamudActCompat/cactbot_user` 逻辑名称，旧备份可以继续恢复。恢复时保留当前电脑已配置且存在的目录；新电脑未配置目录时恢复到默认目录。来自备份的绝对路径不作为写入目标。现有路径联接限制保持，直接选择真实目录即可。

跨盘恢复先在目标盘暂存，并在修改配置前生成加密回滚包。恢复预览比较实际目录；恢复失败会撤销已提交的目录和配置。路径互相包含、备份文件位于 user 目录内等情况会被拒绝。

## 统计重置

“战斗统计 → 统计重置方式”有两个选项：

- **DACT默认**：旧配置和新安装均默认使用，保持原有累计及结束规则。
- **脱战指定秒数后重置**：用户填写 0–3600 秒，初始输入值为 5 秒。重新进入战斗取消倒计时；本人死亡但队伍仍在战斗时也不会触发。到期保存结果并清空统计，下次从零计算。

该设置基于战斗状态，不按 Boss 身份识别。真实脱战较长的转阶段也可能分开，按需调整等待时间。副本内每次结算保存在同一副本历史文件夹内；副本外按独立战斗保存。

重置使用独立的统计分段，不调用共享 ACT 的 `EndCombat`，不停止日志分发，不向兼容 Host 额外发布战斗结束。重置后同一底层 ACT encounter 的后续动作复制到私有统计对象，避免伤害、最高命中、DPS 时长带入上一场。Cactbot 的真实游戏/ACT 战斗状态及邮差接口保持。

## 艾欧泽亚皮肤

艾欧泽亚改为赞助 **3 级及以上**解锁。皮肤收藏、详情和赞助入口提示共用同一等级定义；1、2 级的赞助图标与红色名字继续保留。资格仍由服务器返回的当前账号等级判断，本地配置和云备份不能授予皮肤。既有选择保留，未达到等级时显示默认皮肤。
