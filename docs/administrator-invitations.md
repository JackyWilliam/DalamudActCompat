# 管理员激活码权限

服务端用户详情页可开启或关闭管理员身份。该身份提供客户端无限生成激活码的权限；一次一码、受邀好友信息和服务端封禁规则保持生效。管理员期间的生成记录保留邀请关系，不消耗普通额度，关闭身份后恢复原普通额度。

客户端登录或恢复共用登录时，从邀请列表读取身份；在线期间使用原有 30 秒会话心跳同步身份。客户端按钮只负责展示可用状态，每次生成仍由服务端读取最新身份校验。

晋升弹窗以短暂淡入、轻微缩放和金色粒子庆祝，动画约两秒后停止，保留“我知道了”按钮。通知由服务端保存，每次授予有独立标识；只有本人确认后才标记已读，离线、重启和读取不会丢失通知。取消再授予会重新提醒。切号、退出和撤销身份后，原账号弹窗关闭。

使用用户提供的 `Player26_Icon.png`，原图随客户端打包。好友列表、自己的账号、申请/查找结果、聊天姓名和消息提示中的管理员姓名后显示同一图标。身份来自服务端当前 `isAdmin`；撤销时服务端更新会话修订号，使历史消息姓名标识也在下次好友同步时消失。

新增接口和字段：

- `GET /api/v1/auth/me`：可选 `administrator`，包含 `isAdmin`、`adminGrantId`、`adminNoticePending`。
- `GET /api/v1/invitations`：同名身份字段与 `quotaUsed`；`used` 保持总生成数，普通额度数值字段保留。
- `POST /api/v1/auth/administrator-notice/ack`：仅提交当前显示通知的 `adminGrantId`，以当前登录账号确认。旧通知标识不能确认新一轮晋升。

旧服务端没有这些字段时，客户端默认普通身份。需更新客户端才能显示管理员权限和晋升弹窗。

验证入口：PackageSmokeTests 的 `--administrator-only`；`DACT_TEST_CIMGUI` 可启用真实原生渲染和按钮交互验证，`DACT_NATIVE_UI_OUTPUT` 可保存动画帧。隔离服务端通过 `DACT_ADMINISTRATOR_FIXTURE` 执行真实 C# 自动登录、超过默认额度生成、确认和冷启动不重播的联调。测试始终使用临时账号与数据目录。
