# Job icon assets

These 96 user-provided PNG files are copied into the plugin package at build time.
Runtime code resolves them relative to the installed plugin `Assets/JobIcons` directory;
it does not reference the original developer-machine source directory.

- `Minimal`: 32 icons, 80×80 source canvas
- `Classic`: 32 icons, 144×144 source canvas
- `Flat`: 32 icons, 64×64 source canvas

The project owner must confirm the source and redistribution terms before a public release.
