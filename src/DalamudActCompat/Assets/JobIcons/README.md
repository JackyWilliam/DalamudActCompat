# Job icon assets

These 96 user-provided PNG files are copied into the plugin package at build time.
The project owner identified Gamer Escape's FFXIV icon dictionary as the
source/reference page:
<https://ffxiv.gamerescape.com/wiki/Dictionary_of_Icons#Disciple_of_War.2FMagic_Class_Icons>.

Runtime code resolves the files relative to the installed plugin
`Assets/JobIcons` directory; it does not reference the original
developer-machine source directory.

- `Minimal`: 32 icons, 80×80 source canvas
- `Classic`: 32 icons, 144×144 source canvas
- `Flat`: 32 icons, 64×64 source canvas
