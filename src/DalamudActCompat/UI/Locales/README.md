# 界面翻译

DACT 支持简体中文、繁体中文、英语、日语、德语和法语。UI 语言与游戏区域、解析器语言分别保存。

- 简体中文和英文文案保留在 `UiText.Get(中文, English)` 调用处。其余四种语言的 JSON 以可见英文文案为键，编译时嵌入程序集，运行时无需网络。
- 新增或修改英文文案时，同步更新四个 JSON。找不到翻译时显示英文，避免空白控件。
- 带参数的文案使用 `UiText.Format(中文插值字符串, 英文插值字符串)`，保留 `{0}`、`{1:N0}` 等占位符及格式。不要先拼接参数再查翻译；账号、聊天、备注、路径不能成为翻译键。
- `##` / `###` 后的 ImGui 标识由代码保留，不放入翻译键或译文。命令及插件名称保持原样。
- 新增服务器状态映射在 `SystemStatusText` 中使用完整匹配；未知诊断保留原文。不要对用户数据做全局替换。
- 日语职业名称按日服称谓显示。德语和法语保持既有职业缩写规则。

检查：Release 构建后运行 PackageSmokeTests 的 `--localization-only`。原生界面测试还覆盖语言菜单点击、窄窗口和字体缩放。翻译采用机器辅助初稿并校订核心术语和常用流程；长篇帮助仍可继续由母语使用者润色。
