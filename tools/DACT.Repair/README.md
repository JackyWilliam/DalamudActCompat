# DACT 修复工具（卫月插件）

这是与 DACT 主插件分开的 **Dalamud 插件**，在同一个自定义插件仓库内安装。不是 Windows 软件，无需下载或运行 EXE。

## 用户操作

1. 在 `/xlplugins` 刷新列表，搜索并安装 **DACT 修复工具**。
2. 在已安装列表中**停用 DACT 主插件**，不要卸载它；保持修复工具启用。
3. 打开修复工具（或输入 `/dactrepair`），点击 **备份并修复到 0.4.4.0**。
4. 提示完成后，完整重启一次游戏并重新启用 DACT。修复工具随后可以卸载。

已有 DACT 仓库无需另加地址：

```text
https://raw.githubusercontent.com/JackyWilliam/DalamudActCompatRepo/main/pluginmaster.json
```

只处理错误编号 **4.4.0.0 → 0.4.4.0**。普通旧版本正常更新即可，已经是 0.4.4.0 会显示无需修复。

## 修改范围

- 内置 SHA-256 固定的正式 0.4.4.0 核心包，同步修正真实 DLL、清单和安装目录，包含换肤影响统计背景的修复。点击修复时无需联网。
- 只定位当前启动器中 DACT 的安装目录，不扫描其他用户或另一个启动器；开发加载不会修改真实安装。
- 原错误目录及冲突的目标目录备份到启动器数据目录的 `DACTRepairBackups/时间-随机编号/`。备份不在 `installedPlugins` 内，避免卫月清理旧版本时将其删除。
- 不读取或改写 `pluginConfigs`，保留账号、皮肤、触发器等配置。保留 WorkingPluginId、订阅来源和禁用状态；更新后需重新启用主插件。
- DACT 主插件或 Host 仍在运行、文件被占用、存在较新版本、安装损坏标记或目录联接时停止。失败自动恢复旧安装；若文件锁等阻碍恢复，保留错误提示中的备份目录并联系维护者。
- 修复完成后应重启游戏，**不要在当前会话重新启用旧 DACT 实例**。卫月重启后才会按新目录重新发现正确版本。

不会注入游戏、改游戏文件、结束进程或调用卫月私有卸载接口。

## 开发

`tools/DACT.Repair/build.ps1` 使用 .NET 10 和 Dalamud API 15 构建独立插件，下载并校验固定核心包。可用 `-CorePackage` 和 `-DalamudLibPath` 指定已有包与引用。

隔离测试覆盖真实正式包、备份、配置/其他插件/身份不变、重复运行、三处失败恢复、运行状态与竞争、坏包/清单、文件锁、目录联接及 ZIP 越界。设置 `DACT_TEST_CIMGUI` 和 `-PreviewPath` 时，还使用真实 cimgui 验证运行中/修复中/无需修复时的点击限制。测试不触碰实际安装。

只分发 `DalamudActCompatRepair-0.1.0.0.zip` 和校验文件。该 ZIP 是卫月插件包，不要双击 DLL，也不要手动覆盖主插件目录。
